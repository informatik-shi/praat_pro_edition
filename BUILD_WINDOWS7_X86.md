# Praat Custom — Windows 7 SP1, 32-bit

Отдельная ветка: `codex/windows7-x86`, исходная версия: `custom/main`.
Целевая система: Windows 7 SP1 x86, в том числе ASUS Eee PC 1025C.
Это отдельный профиль сборки с Lua, отладчиками, сворачиванием кода,
траекториями формант и пользовательскими графиками.

## Запуск на нетбуке

1. Распакуйте весь архив выпуска в обычную папку с правом записи.
2. Запустите `praat-win7-x86.exe`. Установка MSYS2 и компилятора на нетбуке
   не требуется. Библиотеки GCC/C++ и winpthread включены в EXE статически;
   графика и редактор используют системные DLL Windows.
3. Для первой проверки откройте небольшой WAV, постройте спектрограмму,
   затем выполните `examples/lua-plot-demo.lua` в Lua Editor.
4. Методичка: `tutorials/lua-plots/README.md`. Для отладчика используйте
   `examples/lua-debugger-demo.lua`: F9 — точка останова, F5 — запуск,
   F10/F11 — шаги; при необходимости нажимайте Fn вместе с функциональной клавишей.

Для небольшого экрана можно развернуть редактор; Praat ограничивает начальный
размер редакторов размерами рабочего стола. При малом объёме памяти работайте
с короткими фрагментами, для длинных записей используйте LongSound. Начните
с одного графика и экспорта PNG в 100–150 dpi. Обычный 32-битный процесс
ограничен примерно 2 ГБ адресного пространства, доступная память может быть
меньше. Whisper и большие модели не являются целевым сценарием этого нетбука.

## Как собрать на современном Windows-компьютере

MSYS2 запускается на компьютере разработчика; поддержка Windows 7 у приложения
не означает, что современный MSYS2 можно установить на Windows 7.

Установите в MSYS2 пакеты:

```bash
pacman -S --needed make mingw-w64-i686-gcc
```

В PowerShell из корня этой ветки, после фиксации изменений в Git:

```powershell
.\build-windows7-x86.ps1 -Jobs 2
```

Профиль: GCC/MINGW32 (MSVCRT), `PRAAT_ARCH=i686`, `-m32`, `-O2`,
`WINVER=0x0601`, `_WIN32_WINNT=0x0601`; PE subsystem 6.1.
Оптимизация под текущий CPU (`-march=native`) и AVX не используются.
Исходники экспортируются из HEAD в новую папку `.local-build/win7-x86-*`,
поэтому объекты x64 из основного checkout не попадают в 32-битную сборку.

Готовый архив для переноса: `dist/praat-win7-x86.zip`.
Результат: `dist/windows7-x86/praat-win7-x86.exe`, документация и примеры
рядом. Соответствующие исходники: `dist/praat-win7-x86-source.zip`.
SHA-256, точный коммит, версии инструментов, импортируемые DLL и логи
проверок находятся в каталоге выпуска. Лог сборки: `.local-build/win7-x86-build.log`.

## Проверки совместимости

Скрипт проверяет PE i386, отсутствие зависимостей UCRT/MSYS/GCC DLL,
выполняет тесты Lua, PNG-графиков, FrequencyTrajectories, модели сворачивания,
обоих отладчиков и привязки графиков к редакторам. Эти проверки
на современной Windows не заменяют запуск на настоящей Windows 7 SP1.
На целевом ASUS нужно отдельно проверить запуск окон, звук, RichEdit,
точки останова и сворачивание, PNG и слои спектрограммы.
