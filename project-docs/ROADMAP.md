# План кастомной сборки

1. **Готово:** скачать официальный код с историей, закрепить базовую версию,
   создать ветку разработки и журнал.
2. **Готово:** подготовить MSYS2/CLANG64, собрать исходную версию
   Windows x64v1, выполнить оба batch-набора и базовую проверку GUI.
   Запись с микрофона и слышимость воспроизведения ещё не проверены.
3. **Реализовано:** встроенный Script IDE, номера строк, syntax highlighting,
   breakpoints, debugger hooks, stepping, Variables, Watch, Call Stack, ошибки.
4. **Реализовано:** интеграционные тесты реального interpreter, Windows exe,
   скрипт сборки и документация. Проверки перечислены в `docs/acceptance.md`.
5. Возможные следующие этапы: source map include/runScript, асинхронный debugger,
   табличный inspector массивов, сохранение Watch, адаптивная тёмная тема.

## Карта исходников для старта

- `main/main_Praat.cpp` — точка запуска и инициализация приложения.
- `fon/praat_Fon.cpp` — регистрация многих команд фонетического анализа.
- `fon/` — обработка звука и фонетические объекты.
- `foned/` — редакторы фонетических объектов.
- `sys/` — инфраструктура приложения, GUI и скрипты.
- `melder/` — базовые функции, строки, ошибки и платформенная поддержка.
- `external/` — встроенные сторонние компоненты.
- `test/`, `dwtest/` — тесты авторов.

Конкретные точки интеграции описаны в `docs/architecture-analysis.md` и
`docs/debugger-architecture.md`.
