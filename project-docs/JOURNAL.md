## 2026-09-11 — встроенный Script IDE/debugger

1. Прочитано подробное техническое задание. Изучены ScriptEditor, TextEditor,
   GuiText, Interpreter, Formula, variablesMap, procedure/call stacks и Makefile.
   Анализ сохранён в `docs/architecture-analysis.md`, коммит `1952ab4ff`.
2. Добавлен необязательный observer настоящего Interpreter, state machine,
   breakpoint/step решения, Stop, реальные Variables/Call Stack, ограниченный
   read-only Watch. Ядро зафиксировано коммитом `8b1db8d92`.
3. Только ScriptEditor переведён на системный RichEdit. Добавлены лексер
   видимых строк, gutter, TOM anchors, сохранение breakpoint, Ln/Col и Debug.
   Интерпретатор не зависит от HWND; WinScriptEditor содержит Windows frontend.
4. Реализован кооперативный event pump в GUI-потоке. Во время исполнения
   исходник readonly, посторонние команды Praat отключены. Формы параметров
   и обычный Run используют исходный путь Praat.
5. Первые компиляции выявили отсутствие Melder_isDigit, несовпадение int/LONG
   в std::max и конфликт имени Polygon. Исправлены явной проверкой цифр,
   правильными типами и Win32 MoveToEx/LineTo. Повторная сборка успешна.
6. Созданы fixtures и C++ integration runner, связанный с библиотеками Praat.
   Проверены реальные остановки, вложенные процедуры, Over/Into/Out, цикл,
   пропущенные ветви, типы, Watch, continuation, Unicode, ошибка и Stop.
   Первый runner прошёл, но grep не прочитал UTF-16 stdout; добавлен --utf8.
7. Windows smoke выявил неверно выбранный родитель окна: внутренний form
   принимался за root и отключал собственный debugger. Разделены host/root.
   Для gutter добавлен SS_NOTIFY, проверены постановка и удаление кликом.
8. Проверены F5, F11, Shift+F11, Watch `.value * 2 = 8`, реальные frames.
   Исправлена перерисовка execution marker: RichEdit больше не переключает
   WM_SETREDRAW на каждом пустом тике; paused-loop явно обновляет children.
   После исправления видны жёлтая строка и стрелка; F10 переходит с 2 на 3.
9. Проверены Shift+F5 без закрытия приложения и runtime error строки 3:
   исходный диалог плюс файл/процедура/строка в Output/Error и навигация.
10. Watch дополнительно закрыт для неизвестных bare symbols (например stopwatch),
    добавлены regression assertions для этого случая и scientific notation.
    Интеграционные тесты повторно прошли.
11. Сгенерирован локальный fixture из 12000 присваиваний. Проверка выявила
    прокрутку дочернего gutter внутри RichEdit; добавлено закрепление его позиции.
