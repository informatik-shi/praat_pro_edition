# Lua в Praat Custom

В сборку включён Lua 5.5.1. Устанавливать Lua или добавлять DLL не нужно.
Исходный Praat Script Editor и его отладчик остаются отдельными инструментами.

## Редактор

В окне Objects откройте **Praat → New Lua script** или **Open Lua script...**.
Редактор сохраняет `.lua`, поддерживает Undo/Redo, поиск и переход к строке.
На Windows доступны номера строк и подсветка ключевых слов, строк, чисел,
однострочных и длинных многострочных комментариев Lua.

- **F5** — запустить скрипт с точками останова / продолжить выполнение.
- **Ctrl+R** — выполнить весь скрипт без отладчика.
- **F9** — переключить точку останова; **F10/F11/Shift+F11** — шаги.
- **Ctrl+T** — выполнить выделенный текст в новом состоянии Lua.
- **F7** — проверить синтаксис, не выполняя код.
- **Shift+F5** — остановить выполнение на ближайшей проверке инструкций.
- `print(...)` выводит текст в окно Praat Info; ошибки содержат файл, строку
  и стек Lua. Номера строк при запуске выделения считаются от начала выделения.

На Windows доступна панель переменных, стека и ошибок: [отладчик Lua](lua-debugger.md).

Каждый запуск получает новое состояние Lua. Объекты Praat сохраняются между
запусками. Уже выполненные команды не откатываются при ошибке или Stop.
Скрипт работает относительно папки сохранённого файла; для нового файла —
относительно текущей рабочей папки Praat.

## API

```lua
local sound = praat.call("Create Sound from formula",
    "tone", 1, 0, 1, 44100, "0.2*sin(2*pi*440*x)")
print(praat.call("Get total duration"))
local spectrum = praat.call("To Spectrum", true)
praat.select(sound)
print(praat.selected()[1])
```

`praat.call(command, ...)` вызывает зарегистрированную команду Objects:
используйте её английское имя. `...` в конце имени можно опустить при наличии
аргументов. Аргументы: числа, строки UTF-8 и логические значения. Формулы Praat
передаются строками. Доступность команды зависит от выбранных объектов.

| Результат команды | Значение Lua |
|---|---|
| Число, целое, логическое значение | number / boolean |
| Строка | string |
| Вектор / массив строк | table с индексами от 1 |
| Матрица | table строк, каждая строка — table |
| Создание объектов | table идентификаторов выбранных после команды объектов |
| Команда без результата | нет возвращаемых значений |

`praat.select(id, ...)` и `praat.select({id, ...})` заменяют выделение.
Все идентификаторы проверяются до изменения выделения. `praat.select({})`
снимает выделение. `praat.selected()` возвращает идентификаторы выделенных
объектов. `praat.objects()` возвращает список `{id, name, class}`; `name`
содержит отображаемое полное имя, включая класс. Удаление: выделить объекты
и вызвать `praat.call("Remove")`.

Ошибку команды можно обработать через `pcall`:

```lua
local ok, message = pcall(praat.call, "Get total duration")
if not ok then print(message) end
```

## Запуск файла и ограничения

**Praat → Run Lua file...** запускает сохранённый файл. Из Praat-скрипта:

```praat
Run Lua file: "demo.lua"
```

Lua имеет стандартный доступ к локальным файлам и процессам через `io` и `os`.
Запуск из обычного Praat-скрипта проходит штатную проверку доверия Praat;
для автоматических тестов используется `--FULL-TRUST`. Явный запуск кода
кнопкой Run в Lua Editor считается доверенным локальным запуском.

`os.exit` отключён, чтобы скрипт не завершал Praat. Нативные модули Lua DLL
не поддерживаются: библиотека встроена статически и собрана как C++.
Модули на Lua через `require` поддерживаются. `debug.sethook` зарезервирован
для отладчика и механизма Stop. Вложенный запуск другого Lua-скрипта через команду Praat
не поддерживается. Остановка внутри длительной команды анализа или блокирующего
вызова `io`/`os` возможна после возврата этой операции; это не отдельный процесс.
Автодополнение и API команд окон редакторов пока не входят
в эту реализацию. Таблицы на входе `praat.call` пока не поддерживаются.

## Сборка и происхождение

Официальный архив: <https://www.lua.org/ftp/lua-5.5.1.tar.gz>.
SHA-256: `1c4b4068d67061f2a2231ad2b5422e77acea1487ea9890f6320af614f4373dce`.
Оригинальные файлы находятся в `external/lua-5.5.1`; добавлен `praat.mk`.
MIT-лицензия Lua содержится в `src/lua.h` и `doc/readme.html`.

Библиотека компилируется как C++, чтобы Lua использовал исключения и корректно
освобождал C++ RAII-объекты в мосте при `lua_error`. Интерпретатор Praat создаётся
на каждый запуск; `Stackel` передаёт типизированные аргументы непосредственно
в `praat_doAction` / `praat_doMenuCommand`, без сборки исходного Praat-скрипта.

Интеграционные тесты: `bash scripts/test-lua.sh` из MSYS2 CLANG64.
Пример: `tests/lua/demo.lua`.
