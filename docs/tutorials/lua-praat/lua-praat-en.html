Lua in your Praat build

A practical course from your first script to a speech-corpus analysis. Familiar Praat tasks, controlled with Lua and illustrated by checkable examples for your build.

29 lessonsLua + phoneticsFrom script to corpus

Your route through the course

Start: 01–07 cover language, objects, formulas, and files. Analysis: 08–16 cover F0, intensity, spectra, annotation, and formants. Continue: 17–23 cover LPC, resynthesis, DTW, and corpora. Visualization and project: 24–29.

Each main example is a separate script. It creates its own input sound unless preparation (lesson 23) or a GUI (lesson 26) is specified. Save examples in a dedicated working folder. Use “Download .lua”, then open the file in Praat.

This course is for speech researchers without Lua experience. Familiarity with opening sounds in Praat and reading waveforms is helpful. Allow 6–8 study sessions including exercises, rather than reading code alone. Commands retain their English names because those are the names accepted by the Lua bridge.

HTML is the textbook, not a Praat execution environment. Buttons copy or download text; run analysis in your application. The document works offline; external links are only for sources. File-writing examples replace their own output files on rerun.

Main batch examples were checked with local dist/praat-custom.exe; overlay example 26 requires a separate GUI check. Appendices describe API limits. Successful execution does not replace listening and visual validation of phonetic conclusions.

Lesson 01 · Book: 1, 2, 4

First run: a sound in one minute

Goal: create a sound, query its duration, and learn where Lua runs. Your build already embeds the interpreter; these lessons need no separate Lua, Python, or DLL installation. In the Objects window, choose Praat → New Lua script. Paste the code and save it as 01-start.lua in a dedicated course folder.

  1. Press F7: syntax checking creates no objects.
  2. Press Ctrl+R to run the whole file. Open Info if it is hidden.
  3. Objects now contains Sound lesson_tone. Select it and press Play to listen, or View & Edit to inspect it.
  4. Run again: another object appears. This is expected; names need not be unique.
01-start.lua · Lua
local sound = praat.call("Create Sound from formula",
    "lesson_tone", 1, 0, 1, 44100, "0.2*sin(2*pi*200*x)")[1]
print(_VERSION)
print("duration_s", praat.call("Get total duration"))
print("samples", praat.call("Get number of samples"))
print("object_id", sound)

Check: Info reports Lua 5.5, duration 1, 44100 samples, and a positive object ID. The embedded library is 5.5.1; _VERSION only reports 5.5. F5 runs with the debugger; Ctrl+R is convenient for this first lesson.

Exercise

Change the duration to 0.5 s and the frequency to 400 Hz. How many samples should you get?

Answer and check

22050 at a sample rate of 44100 Hz. Tone frequency changes the number of cycles, but sample count depends on duration and sample rate.

Lesson 02 · Book: 4; A

Essential Lua

Lua handles parameters, branches, repetition, and result collection. Praat commands perform signal analysis. Prefer local variables. Use a decimal point in numbers and straight quotation marks in strings. A comment starts with --.

SyntaxMeaning
== / ~=equal / not equal
..concatenate strings
^exponentiation
#valueslength of a dense sequence
and / or / notlogical operations

Only false and nil are false: zero and an empty string are true. Sequences in this course start at 1; a negative index does not mean “from the end”. ipairs stops at the first missing element.

02-lua.lua · Lua
local frequencies = {100, 200, 400}
local sum = 0
for i, hz in ipairs(frequencies) do
    sum = sum + hz
    local label = hz >= 200 and "high" or "low"
    print(i, hz, label)
end
local function period(hz)
    assert(hz > 0, "Frequency must be positive")
    return 1 / hz
end
print("sum", sum)
print("period_s", period(200))
print("pi", math.pi, "sin(pi/2)", math.sin(math.pi / 2))
local n = 0
repeat n = n + 1 until n == 3
while n > 0 do n = n - 1 end
assert(n == 0)

Result: sum 700, period 0.005 s, sine approximately 1. local function defines a function; return returns a value. A table can be a sequence or a set of named fields such as {floor=75, ceiling=500}. pairs visits fields in unspecified order. break exits a loop. Do not use # to count arbitrary named fields.

Exercise

Add 800 Hz to the table and print the mean frequency.

Answer and check

frequencies[#frequencies+1] = 800; recompute the sum in a loop and divide by #frequencies. The result is 375 Hz.

Lesson 03 · Book: 1.5; 4.8

Objects, selection, and return types

A command depends on the current Objects selection. Lua represents a Praat object by a numeric ID, not by its sample array. Creation commands return a table of IDs selected after the command. For a single-object creation, take [1]. An ID is neither a list-row number nor a Lua index.

03-objects.lua · Lua
local sound = praat.call("Create Sound from formula",
    "lesson_tone", 1, 0, 1, 44100, "0.2*sin(2*pi*200*x)")[1]
local spectrum = praat.call("To Spectrum", true)[1]
praat.select(sound)
print("duration_s", praat.call("Get total duration"))
for _, object in ipairs(praat.objects()) do
    print(object.id, object.class, object.name)
end
assert(praat.selected()[1] == sound)
praat.select({sound, spectrum})
assert(#praat.selected() == 2)
praat.select(spectrum)
praat.call("Remove")
praat.select(sound)
APIResult / action
praat.call(name, ...)number, boolean, string, table, or no return values
praat.select(id, ...)replaces selection; also accepts a table of IDs
praat.select({})clears selection
praat.selected()table of selected IDs
praat.objects()all objects: {id, name, class}; name includes the class
Creating an object usually changes selection. Explicitly select the saved ID before querying the required type. Remove only your own intermediate objects: deleting every object may destroy the user’s work.

Exercise

Create a Copy of the sound with the same name. Is selection by name safe?

Answer and check

No: names can repeat. local copy = praat.call("Copy", "lesson_tone")[1] gives a distinct unique ID.

Lesson 04 · Book: 4.1, 4.5–4.10

Translating commands and the two formula languages

Use the registered English command name and pass arguments in dialog order, top to bottom. Trailing ellipses can be omitted when arguments are supplied. Lua does not automatically provide named arguments for Praat dialogs. Names and strings use UTF-8.

Outside a string, use math.sin and math.pi; inside a Praat formula, use sin, pi, x, self, row, and col. Lua variables are invisible to the formula interpreter. Insert a numeric parameter with string.format.

04-bridge.lua · Lua
local hz, amplitude = 300, 0.15
local formula = string.format("%.17g*sin(2*pi*%.17g*x)", amplitude, hz)
local sound = praat.call("Create Sound from formula",
    "parameterised", 1, 0, 1, 44100, formula)[1]
praat.call("Formula", "self - 0.01")
praat.call("Subtract mean")
print("rms_Pa", praat.call("Get root-mean-square", 0, 0))
praat.call("Create simple Matrix", "matrix_demo", 2, 3, "row*10+col")
local matrix = praat.call("Get all values")
assert(matrix[2][3] == 23)
print("matrix_2_3", matrix[2][3])

For amplitude 0.15, RMS is approximately 0.106066 Pa. A returned vector or string array becomes a 1-based table; a matrix becomes a table of rows. Ordinary tables cannot be passed into praat.call: its arguments must be numbers, booleans, or strings. Tables are accepted by praat.select for selecting multiple objects.

Exercise

How do you express “tone for the first half-second, then silence” in a formula?

Answer and check

"if x < 0.5 then 0.2*sin(2*pi*200*x) else 0 fi". This is Praat syntax. A Lua conditional ends with end.

Lesson 05 · Book: 2, 3; A

Samples, units, and sampling

A sound is a sequence of amplitude values at particular times. The sampling frequency Fs counts samples per second, not pitch. A tone at frequency f has period T = 1/f. The Nyquist frequency is Fs/2: synthesized components must lie below it. Changing sample-rate metadata and properly resampling are different operations.

Query sample times from the object. The first sample need not occur at zero; it usually sits at the centre of the first sampling interval. Channels start at 1.

05-sampling.lua · Lua
local sound = praat.call("Create Sound from formula",
    "lesson_tone", 1, 0, 1, 44100, "0.2*sin(2*pi*200*x)")[1]
local fs = praat.call("Get sampling frequency")
local n = praat.call("Get number of samples")
local peak, squareSum = 0, 0
for i = 1, n do
    local value = praat.call("Get value at sample number", 1, i)
    peak = math.max(peak, math.abs(value))
    squareSum = squareSum + value * value
end
print("Fs_Hz", fs, "Nyquist_Hz", fs / 2)
print("first_time_s", praat.call("Get time from sample number", 1))
print("peak_Pa", peak, "rms_Pa", math.sqrt(squareSum / n))
assert(math.abs(math.sqrt(squareSum / n) - 0.2/math.sqrt(2)) < 1e-6)
local resampled = praat.call("Resample", 16000, 50)[1]
assert(praat.call("Get number of samples") == 16000)

Expect peak near 0.2 Pa and RMS near 0.141421 Pa. The loop is educational, but each bridge call has overhead: use Get root-mean-square for a large file. WAV values are normally normalized on reading; physical SPL requires calibration. The usual ±1 PCM normalization on file output is not a universal limit on internal Sound values.

Exercise

Synthesize 900 Hz at Fs=1000 Hz. Why is the result not a faithfully represented 900 Hz tone?

Answer and check

900 Hz exceeds the 500 Hz Nyquist frequency and aliases to 100 Hz. Faithful representation needs Fs strictly above 1800 Hz, with practical filtering margin.

Lesson 06 · Book: 3, 4

Reading, writing, and the working folder

A saved script runs relative to its own folder. A new unsaved script uses Praat’s current working folder. Save the script before file lessons. On Windows, forward slashes are convenient: C:/speech/token.wav; a long string such as [[C:\speech\token.wav]] is another option.

The example creates its own WAV, reads it, and extracts a segment. Extract part takes start, end, window shape, relative width, and Preserve times. False resets the segment’s start to zero; true retains the original time coordinates.

06-files.lua · Lua
local sound = praat.call("Create Sound from formula",
    "lesson_tone", 1, 0, 1, 44100, "0.2*sin(2*pi*200*x)")[1]
praat.call("Save as WAV file", "lesson-tone.wav")
local loaded = praat.call("Read from file", "lesson-tone.wav")[1]
print("loaded_duration_s", praat.call("Get total duration"))
local part = praat.call("Extract part", 0.2, 0.5, "rectangular", 1, false)[1]
assert(math.abs(praat.call("Get total duration") - 0.3) < 1e-9)
praat.call("Save as WAV file", "lesson-part.wav")
local lfs = require("lfs")
print("folder", lfs.currentdir())
print("wav_bytes", lfs.attributes("lesson-tone.wav", "size"))
Rerunning replaces lesson-tone.wav and lesson-part.wav. Use a dedicated exercise folder. Archive settings and TextGrid alongside audio; WAV does not contain Pitch/Formant objects. On Windows, LuaFileSystem filenames are limited by the system code page: use Praat file commands or simple ASCII names for paths outside it.

Lesson 07 · Book: 4.4, 4.10–4.12

Functions, parameters, and input validation

Put repeated analysis into functions and parameters into a table at the top. Names with units, such as duration_s, help avoid confusing seconds and milliseconds. assert stops execution with an explanation when a condition fails. Functions should return results explicitly and manage selection predictably.

07-functions.lua · Lua
local settings = {duration_s=0.5, sample_rate_Hz=44100, amplitude=0.1}
local function makeTone(hz, cfg)
    assert(hz > 0 and hz < cfg.sample_rate_Hz/2, "Invalid frequency")
    assert(cfg.duration_s > 0, "Duration must be positive")
    local formula = string.format("%.17g*sin(2*pi*%.17g*x)", cfg.amplitude, hz)
    return praat.call("Create Sound from formula", "tone_" .. hz,
        1, 0, cfg.duration_s, cfg.sample_rate_Hz, formula)[1]
end
local function rms(id)
    praat.select(id)
    return praat.call("Get root-mean-square", 0, 0)
end
for _, hz in ipairs({100, 200, 400}) do
    local id = makeTone(hz, settings)
    print(hz, rms(id))
    praat.select(id)
    praat.call("Remove")
end

All three RMS values are approximately 0.070711 Pa. Lua does not understand the native Praat form ... endform syntax. For simple interactive use, edit settings; for batch runs, use arg. Pure Lua modules can live in a neighbouring file that returns a function table, loaded with require("analysis"). Each new run loads them into a fresh state.

Exercise

Validate a positive sample rate and constrain amplitude to 0 through 0.9.

Answer and check

assert(cfg.sample_rate_Hz > 0) and assert(cfg.amplitude >= 0 and cfg.amplitude <= 0.9). These are generator policies, not Sound type limits.

Lesson 08 · Book: 5

Fundamental frequency F0 and missing values

F0 describes repetition of oscillations, whereas formants describe vocal-tract resonances. They are different quantities. This example uses the simple three-argument To Pitch: time step, pitch floor, and pitch ceiling. Zero time step selects automatic spacing. Explicit analysis settings make the experiment reproducible; Pitch display settings in SoundEditor do not replace them.

Unvoiced regions and silence may have undefined F0. Numeric undefined arrives as NaN, which is unequal to itself. if value then is insufficient because NaN is true in Lua. Never replace missing values by zeros when calculating mean F0.

08-pitch.lua · Lua
local sound = praat.call("Create Sound from formula",
    "lesson_tone", 1, 0, 1, 44100, "0.2*sin(2*pi*200*x)")[1]
local pitch = praat.call("To Pitch", 0.01, 75, 500)[1]
local n = praat.call("Get number of frames")
local valid, total = 0, 0
for frame = 1, n do
    local hz = praat.call("Get value in frame", frame, "Hertz")
    if hz == hz and hz > 0 and hz < math.huge then
        valid, total = valid + 1, total + hz
    end
end
assert(valid > 0, "No voiced frames")
local mean = total / valid
print("voiced_frames", valid, "all_frames", n)
print("frame_mean_F0_Hz", mean)
print("median_F0_Hz", praat.call("Get quantile", 0, 0, 0.5, "Hertz"))
assert(math.abs(mean - 200) < 2)

On the tutorial tone, mean and median are close to 200 Hz. For speech, choose a speaker-appropriate range and inspect octave errors: jumps by a factor of about two may be tracking errors. The valid-frame fraction describes the algorithm’s output under these settings, not a ready-made measure of voiced-speech proportion. Source chapter 5 discusses candidates and path selection; Lua automates the analysis here.

Exercise

Replace the sound formula by "0". What should the script do?

Answer and check

Report No voiced frames rather than divide by zero or report F0=0. In a corpus workflow, record NA and continue with the other files.

Lesson 09 · Book: 6

Intensity and silence detection

Intensity is a smoothed energy-related measure in decibels. Its pitch-floor parameter controls the analysis-window length; it does not measure F0. Doubling the amplitude of the same signal raises the level by about 6.02 dB. Physical SPL is meaningful only for calibrated amplitudes.

Specify the averaging method: energy averages energy before conversion to dB, while dB averages the decibel values. They generally differ. The silence threshold in the following command is in dB relative to maximum intensity.

09-intensity.lua · Lua
local sound = praat.call("Create Sound from formula", "pause_demo",
    1, 0, 1, 44100,
    "if x>0.25 and x<0.75 then 0.2*sin(2*pi*200*x) else 0 fi")[1]
local intensity = praat.call("To Intensity", 75, 0.01, true)[1]
print("energy_mean_dB", praat.call("Get mean", 0, 0, "energy"))
print("median_dB", praat.call("Get quantile", 0, 0, 0.5))
local grid = praat.call("To TextGrid (silences)",
    -25, 0.10, 0.10, "silent", "sounding")[1]
print("intervals", praat.call("Get number of intervals", 1))
praat.call("Save as text file", "lesson-silences.TextGrid")

The output includes Intensity and a TextGrid with silent/sounding intervals. Boundaries lie near 0.25 and 0.75 s, but smoothing and minimum-duration rules shift them. This is energy-based segmentation, not word recognition or reliable phoneme-boundary detection. Listen and correct it before making measurements.

Exercise

What happens if minimum silence duration is increased to 0.4 s?

Answer and check

Short silent intervals may merge into neighbouring sounding regions. Inspect the resulting intervals, not just the absence of an execution error.

Lesson 10 · Book: 7

Spectrum, phase, and resolution

A Spectrum describes the frequency content of the entire selected sound. It does not show when a frequency occurred. For a stationary segment of duration T, the characteristic resolution scale is roughly 1/T. FFT zero-padding densifies the frequency grid but adds no information and does not by itself resolve nearby components.

Spectrum stores real and imaginary components. Their magnitude is useful for comparisons within the same procedure, but it must not be labelled spectral density in dB/Hz without appropriate normalization.

10-spectrum.lua · Lua
local sound = praat.call("Create Sound from formula", "mixture",
    1, 0, 1, 16000, "0.2*sin(2*pi*200*x)+0.1*sin(2*pi*600*x)")[1]
local spectrum = praat.call("To Spectrum", true)[1]
local n = praat.call("Get number of bins")
local bestHz, bestMagnitude = 0, -1
for bin = 1, n do
    local re = praat.call("Get real value in bin", bin)
    local im = praat.call("Get imaginary value in bin", bin)
    local magnitude = math.sqrt(re*re + im*im)
    if magnitude > bestMagnitude then
        bestMagnitude = magnitude
        bestHz = praat.call("Get frequency from bin number", bin)
    end
end
print("largest_bin_Hz", bestHz)
assert(math.abs(bestHz - 200) < 2)

The strongest bin is near 200 Hz; the second component is near 600 Hz. Shorten the duration to 0.02 s and inspect peak broadening. Do not equate the largest spectral peak, F0, and F1: in a complex signal they may differ.

Exercise

Replace the 600 Hz sine by a cosine. What changes?

Answer and check

That component’s phase and the mixture’s waveform change. Under matching conditions, its spectral-peak magnitude remains practically the same.

Lesson 11 · Book: 8

Spectrograms and the window trade-off

A spectrogram is a sequence of local spectra. A short window localizes rapid events; a long window better separates nearby frequencies and harmonics. Smaller time steps add frames but do not remove window-induced smearing. Smaller frequency steps densify the grid but do not substitute for a longer window.

To Spectrogram arguments are window length in seconds, maximum frequency in Hz, time step in seconds, frequency step in Hz, and window shape. This example creates a linear frequency sweep: phase needs an x² term because instantaneous frequency is the derivative of phase divided by 2π.

11-spectrogram.lua · Lua
local sound = praat.call("Create Sound from formula", "chirp",
    1, 0, 1, 16000, "0.2*sin(2*pi*(200*x+900*x*x))")[1]
local wide = praat.call("To Spectrogram", 0.005, 4000, 0.002, 20, "Gaussian")[1]
praat.select(sound)
local narrow = praat.call("To Spectrogram", 0.04, 4000, 0.002, 20, "Gaussian")[1]
print("spectrogram_ids", wide, narrow)
praat.call("Save as text file", "lesson-spectrogram.txt")

In Objects, select each Spectrogram and press View to compare. Frequency starts near 200 Hz and ends near 2000 Hz. For speech, compare wideband and narrowband views of the same segment. SoundEditor’s interactive spectrogram and the created Spectrogram object have separate settings.

Exercise

Why does reducing frequency step from 20 to 5 Hz not guarantee separating two tones 10 Hz apart?

Answer and check

Grid density and actual resolution differ. You need a sufficiently long window, a suitable window shape, and adequate stationarity within it.

Lesson 12 · Book: 2.7, 7.5, 11

Filtering, noise, and impulse responses

A filter changes frequency-component amplitude and phase. A band-pass filter retains a selected band; a formant filter models a resonance. Work on a copy or a converted result and compare it with the original. Normalizing afterwards helps listening but conceals level changes: measure RMS before normalization.

Pass Hann band takes lower frequency, upper frequency, and smoothing width in Hz. It returns a new Sound. An impulse response shows the system’s response to a short impulse; it is not an arbitrary noise response.

12-filters.lua · Lua
local original = praat.call("Create Sound from formula", "two_tones",
    1, 0, 1, 16000, "0.2*sin(2*pi*200*x)+0.2*sin(2*pi*2000*x)")[1]
local before = praat.call("Get root-mean-square", 0, 0)
local filtered = praat.call("Filter (pass Hann band)", 100, 500, 50)[1]
local after = praat.call("Get root-mean-square", 0, 0)
print("RMS_before_after", before, after)
assert(after < before)
praat.call("Save as WAV file", "lesson-filtered.wav")
local impulse = praat.call("Create Sound from formula", "impulse",
    1, 0, 0.1, 16000, "if col=1 then 1 else 0 fi")[1]
local response = praat.call("Filter (one formant)", 800, 80)[1]
praat.call("Save as WAV file", "lesson-response.wav")

After filtering, mainly the 200 Hz component remains; RMS drops from about 0.2 to 0.141 Pa. The resonator response contains decaying oscillations near 800 Hz. When comparing filters, report transition-band settings and edge handling. For demonstrations, Praat formula randomGauss(0,0.05) generates noise; it uses a different generator from Lua’s math.random.

Exercise

Increase resonator bandwidth from 80 to 160 Hz. How does decay change?

Answer and check

Decay becomes faster: a wider bandwidth corresponds to shorter ringing. Compare envelopes on identical time scales.

Lesson 13 · Book: 9

TextGrid: intervals and labels

A TextGrid stores annotations, not audio. An IntervalTier contains intervals; a PointTier contains individual events. To TextGrid creates tiers by name: the first argument lists all tiers, and the second lists those that should be point tiers. An empty second string creates only interval tiers.

For the tutorial tone, annotate two regions using predetermined times. For real speech, choose boundaries by listening and context. A zero crossing can reduce a cut-induced click but does not define a linguistic boundary.

13-textgrid.lua · Lua
local sound = praat.call("Create Sound from formula",
    "lesson_tone", 1, 0, 1, 44100, "0.2*sin(2*pi*200*x)")[1]
local grid = praat.call("To TextGrid", "segments events", "events")[1]
praat.call("Insert boundary", 1, 0.4)
praat.call("Set interval text", 1, 1, "part_A")
praat.call("Set interval text", 1, 2, "part_B")
praat.call("Insert point", 2, 0.4, "transition")
local count = praat.call("Get number of intervals", 1)
for interval = 1, count do
    local a = praat.call("Get start time of interval", 1, interval)
    local b = praat.call("Get end time of interval", 1, interval)
    local label = praat.call("Get label of interval", 1, interval)
    print(label, a, b, b-a)
end
praat.call("Save as text file", "lesson-annotation.TextGrid")

Result: part_A lasts 0.4 s and part_B lasts 0.6 s. To edit manually after the script finishes, select Sound and TextGrid together and press View & Edit. In the custom View & Edit selected combined editor, TextGrid may be a viewing layer; use the standard TextGridEditor to change labels.

Exercise

Why should Get number of intervals not be applied to the events tier?

Answer and check

It is a PointTier. Use point-tier commands, such as Get number of points with the tier number, rather than interval commands.

Lesson 14 · Book: 9; 13.3.5

Measuring annotated regions

The core corpus-analysis pattern is to read boundaries from TextGrid, select the analysis object, and query the same time region. Avoid recreating Pitch for each short interval without a reason: full-sound analysis retains window context. TextGrid coordinates must match Sound and Pitch coordinates.

The example measures median F0 over two intervals. It explicitly switches selection between TextGrid and Pitch; the same command name, such as Get mean, can have very different arguments for different object classes.

14-intervals.lua · Lua
local sound = praat.call("Create Sound from formula",
    "lesson_tone", 1, 0, 1, 44100, "0.2*sin(2*pi*200*x)")[1]
local grid = praat.call("To TextGrid", "segments", "")[1]
praat.call("Insert boundary", 1, 0.5)
praat.call("Set interval text", 1, 1, "early")
praat.call("Set interval text", 1, 2, "late")
praat.select(sound)
local pitch = praat.call("To Pitch", 0.01, 75, 500)[1]
praat.select(grid)
local n = praat.call("Get number of intervals", 1)
for i = 1, n do
    praat.select(grid)
    local label = praat.call("Get label of interval", 1, i)
    local a = praat.call("Get start time of interval", 1, i)
    local b = praat.call("Get end time of interval", 1, i)
    if label ~= "" and b > a then
        praat.select(pitch)
        local hz = praat.call("Get quantile", a, b, 0.5, "Hertz")
        local value = hz == hz and string.format("%.3f", hz) or "NA"
        print(label, b-a, value)
    end
end

Both medians are near 200 Hz. Missing values are represented as NA. For real data, specify a policy: skip empty labels, exclude particular silence labels, or retain them with NA. Do not make that policy implicit: an empty label and a label named silent are different cases.

Exercise

Query F0 at each interval midpoint instead of its median.

Answer and check

praat.call("Get value at time", (a+b)/2, "Hertz", "linear") with Pitch selected. This is a point estimate and can differ from the interval median.

Lesson 15 · Book: 10, 12

Vowels, VowelEditor, and KlattGrid

VowelEditor is useful for manually exploring vowel space. This bridge does not provide a general editor-window command API: do not try to send editor gestures through praat.call. Use KlattGrid object commands for reproducible synthesis from Lua.

The source–filter model separates source oscillation (F0) from resonances (F1, F2, and higher formants). The example creates a steady vowel-like sound with specified resonances. It is a teaching model, not a reference pronunciation for a phoneme or speaker.

15-synthesis.lua · Lua

Formants: measurement and validation

Formant analysis estimates resonances with a model rather than simply finding bright bands. A synthetic vowel provides controlled input settings for comparing estimates. Burg arguments are time step, maximum number of formants, frequency ceiling, window length, and pre-emphasis frequency.

Five formants and a 5500 Hz ceiling are a teaching starting point. For real speakers, inspect ceiling, model order, F1/F2 stability, and the spectrogram. High F0, nasal resonances, and noise complicate estimation. Estimated values need not exactly reproduce synthesis settings.

Model order is related to the number of poles, not identical to the number of formants. Match the sampling rate to the frequency range of interest before analysis.

The example explicitly resamples a synthetic vowel to 11000 Hz and fits an order-10 LPC model. Unlike To Formant (burg), this exposes LPC parameters directly. Pre-emphasis boosts higher frequencies for analysis; it does not improve the original recording.

Lesson 18 · Book: 5.2, 15

PointProcess and periodicity

A PointProcess stores event times. For voice analysis, these may be estimated periodic pulses. They support period and jitter measurements. Results depend on pulse extraction and period constraints; a point count is not the duration of voiced speech.

Local jitter measures relative variation between neighbouring periods. A clean synthetic tone should give a small value. This is a teaching measurement, not a medical diagnosis. Shimmer also requires the original Sound and measures amplitude variation.

18-pulses.lua · Lua
local sound = praat.call("Create Sound from formula",
    "lesson_tone", 1, 0, 1, 44100, "0.2*sin(2*pi*200*x)")[1]

print("pulse_count", praat.call("Get number of points"))

assert(jitter == jitter and jitter < 0.01)

A 200 Hz tone has a 0.005 s period and roughly 200 points, with some edge losses. Jitter is returned as a fraction; multiply by 100 for percent. Too few valid periods can produce undefined. Use identical methods and constraints for comparisons and inspect pulse locations against the waveform.

Lesson 20 · Book: 17

MFCC and dynamic time warping

MFCC compress local spectral shape into coefficients. They are features, not formant frequencies. DTW aligns time sequences at different speaking rates by finding a path through a local-distance matrix. A small distance alone does not establish the same phonetic category.

Start by comparing a vowel with a copy of itself: this checks the entire workflow without a corpus. To MFCC takes coefficient count, window length, time step, first filter frequency, filter spacing, and maximum frequency; the last three use mel. A zero maximum selects the available range.

Lesson 22 · Book: 4.12; расширение сборки / build extension

Errors, cleanup, and session state

Every run creates a fresh Lua state: variables and the previous require cache disappear. Praat objects remain. Errors and Stop do not roll back completed commands or written files. A long analysis therefore needs explicit cleanup of its own temporary objects.

pcall returns true plus function results, or false plus an error. Check numeric finiteness separately from execution success: a command may return NaN without raising an exception. The following pattern tracks only objects created between a snapshot and completion of an operation.

22-errors.lua · Lua
local before, previous = {}, praat.selected()
for _, object in ipairs(praat.objects()) do before[object.id] = true end
local ok, message = pcall(function()
    praat.call("Create Sound from formula", "temporary", 1, 0, 1, 16000, "0")
    praat.call("This command deliberately does not exist")
end)
local created = {}
for _, object in ipairs(praat.objects()) do
    if not before[object.id] then created[#created+1] = object.id end
end
if #created > 0 then praat.select(created); praat.call("Remove") end
praat.select(previous)
assert(not ok)
print("handled_error", message)
This snapshot pattern fits a synchronous operation in the current build provided it does not delete pre-existing objects. Production code can be more precise by tracking every created ID directly. Stop caught by pcall is also a Lua error; do not create an endless retry loop that swallows stop requests.

Folder processing and the command line

Preparation: create a corpus folder beside the script and place WAV files in it. For a first run, copy lesson-tone.wav and lesson-part.wav from lesson 6. The script reads only top-level WAV files, sorts names, and writes a new lesson-batch.tsv. A different folder can be supplied as the first command-line argument.

The script removes objects created while processing each file and restores previous selection. A file that cannot be read gets an ERROR row and processing continues. A missing measurement gets NA. Detailed errors go to Info.

23-batch.lua · Lua
local lfs = require("lfs")
local folder = (arg and arg[1]) or "corpus"
assert(lfs.attributes(folder, "mode") == "directory", "Create the corpus folder first")
local files = {}
for name in lfs.dir(folder) do
    if name:lower():match("%.wav$") and
       lfs.attributes(folder .. "/" .. name, "mode") == "file" then
        files[#files+1] = name
    end
end
table.sort(files)
assert(#files > 0, "No WAV files found")
local function cell(value)
    return tostring(value):gsub("[\t\r\n]", " ")
end
local function number(value)
    if value == value and math.abs(value) < math.huge then
        return string.format("%.6f", value)
    end
    return "NA"
end
local output = assert(io.open("lesson-batch.tsv", "w"))
output:write("file\tduration_s\tmedian_F0_Hz\tstatus\n")
for _, name in ipairs(files) do
    local before, previous = {}, praat.selected()
    for _, o in ipairs(praat.objects()) do before[o.id] = true end
    local ok, duration, median = pcall(function()
        praat.call("Read from file", folder .. "/" .. name)
        local seconds = praat.call("Get total duration")
        praat.call("To Pitch", 0.01, 75, 500)
        return seconds, praat.call("Get quantile", 0, 0, 0.5, "Hertz")
    end)
    local temporary = {}
    for _, o in ipairs(praat.objects()) do
        if not before[o.id] then temporary[#temporary+1] = o.id end
    end
    if #temporary > 0 then praat.select(temporary); praat.call("Remove") end
    praat.select(previous)
    if not ok and tostring(duration):find("Lua execution stopped", 1, true) then
        output:close()
        error(duration, 0)
    end
    if ok then
        output:write(cell(name), "\t", number(duration), "\t", number(median), "\tOK\n")
    else
        output:write(cell(name), "\tNA\tNA\tERROR\n")
        print("ERROR", name, duration)
    end
    output:flush()
end
output:close()
print("files_processed", #files)

For a readable file, status=OK means the procedure executed, not that its phonetic interpretation is valid. Very short sounds may not support To Pitch. Stop leaves a partial TSV. Bridge limitations

Objects commands and relevant global menus are supported. A general editor-command API, autocomplete, plot Lua callbacks, and direct Sound-array editing through tables are not implemented. os.exit, debug.sethook replacement, and third-party native Lua DLL loading are disabled; pure Lua modules, lfs, and praat.plot are available. Nested Run Lua file calls from Lua are forbidden. Standard io/os can access local files and processes; run scripts whose actions you understand.

Plot limits

Up to a 4×4 grid, 128 series per Axes, and 1,000,000 numeric values per Figure. Arrays must be dense, nonempty, and finite; x/y lengths must match. Matrices must be rectangular, at most 1000×1000 within the global limit. Legends show up to 8 series. Figure dimensions are 3–24 inches; PNGs are limited to 40 megapixels. No 3D, logarithmic axes, PDF/SVG, colour bars, shared clim, or animation. Axes configuration returns Axes; plot/scatter/bar return a series, so do not chain set_xlabel after them.
