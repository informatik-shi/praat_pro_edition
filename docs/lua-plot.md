# Кастомная визуализация из Lua

Первый этап — самостоятельное окно графиков на движке Praat, с API в духе
matplotlib. Модуль встроен в EXE: Python, pip и отдельная установка Lua не нужны.
Это небольшой собственный API, а не полная совместимость с matplotlib.

Откройте `examples/lua-plot-demo.lua` через **Praat → Open Lua script...**
и нажмите **F5**. Исходник примера: `tests/lua-plot/demo.lua`.

```lua
local plt = require('praat.plot')
local fig, ax = plt.subplots(1, 1, {title='Мой график'})
ax:plot({0, 1, 2, 3}, {0, 2, 1, 4}, {
    color='#1f77b4', linewidth=2, label='Измерения'
})
ax:set_xlabel('Время, с'):set_ylabel('Значение'):legend()
fig:show()
fig:savefig('my-figure.png', 150)
```

## Figure и axes

`plt.figure{title=..., width=9, height=6}` создаёт фигуру. Размеры в дюймах
используются при PNG-экспорте. `fig:add_subplot(rows, cols, index)` добавляет оси
в сетку; index начинается с 1, слева направо и сверху вниз.

`plt.subplots(rows, cols, options)` возвращает фигуру и axes. Для одной ячейки
это объект axes, для нескольких — плоская таблица `axes[1]`, `axes[2]` и т.д.
Максимальная сетка 4×4. Повторный add_subplot с тем же индексом возвращает
существующие axes; смешивать сетки одной фигуры нельзя.

| Метод axes | Параметры |
| --- | --- |
| `ax:plot(x, y, options)` | Линии; color, linewidth, label |
| `ax:scatter(x, y, options)` | Точки; color, size (диаметр в мм), label |
| `ax:bar(x, y, options)` | Столбцы от нуля; color, width (в единицах x), label |
| `ax:imshow(matrix, {extent={xmin,xmax,ymin,ymax}})` | Прямоугольная числовая матрица, тепловая карта |
| `ax:set_title(text)` | Заголовок подграфика |
| `ax:set_xlabel(text)`, `ax:set_ylabel(text)` | Подписи осей |
| `ax:set_xlim(min,max)`, `ax:set_ylim(min,max)` | Возрастающие границы осей |
| `ax:grid(false)`, `ax:legend()` | Сетка и легенда |
| `ax:clear()` | Удалить серии и явные границы axes |

Для `plot(y)`, `scatter(y)`, `bar(y)` x автоматически равен 1..#y. Чтобы
передать options, задайте x и y явно. Возвращаемое значение plot/scatter/bar —
таблица серии; остальные методы настройки axes возвращают сами axes.

Цвет — `#RRGGBB` или red/blue/green/black/orange; без цвета используется цикл
из шести цветов. Поддерживаются Unicode-подписи. Это буквальные подписи,
без математической разметки matplotlib.

Матрица imshow имеет одинаковую длину всех строк. Первая строка находится
**снизу**. Без extent используются границы 0..число столбцов и 0..число строк.
Каждая карта нормируется по своему минимуму/максимуму и использует встроенную
палитру от синего к жёлтому. В текущей версии нет colorbar и общего clim.

## Работа с окном

`fig:show()` открывает отдельное окно или обновляет ранее открытое окно этой
фигуры. Оно содержит копию данных и работает после завершения Lua. Закрытие
окна не оставляет ссылок на освобождённое состояние Lua. `fig:close()` закрывает
окно; повторный close допустим, следующий show создаёт его заново.

Выделите мышью прямоугольный участок внутри axes, чтобы приблизить его.
Щелчок выбирает axes для **View → Zoom in / Zoom out**. **Ctrl+H** или
**View → Reset view** возвращает исходные границы всех axes. Изменение размера
окна перерисовывает данные. Действия масштабирования действуют на копию в окне;
повторный show возвращает вид, заданный Lua-моделью.

Окно предназначено для взаимодействия после завершения скрипта. Во время
длительного выполнения Lua его управляющие события не обрабатываются.

## PNG-экспорт

`fig:savefig('file.png', dpi)` экспортирует Lua-модель, независимо от ручного
масштабирования окна. Поддерживаются DPI **100, 150 (по умолчанию), 300, 600**.
Размер фигуры — 3..24 дюйма по каждой стороне, максимум 40 мегапикселей.
Относительный путь считается от папки скрипта; существующий файл заменяется.
`savefig` доступен и в batch-режиме; `show` требует GUI.

## Границы первого этапа и дальнейшее встраивание

Готовы 2D-графики, отдельное окно и PNG. Встраивание в Sound Editor и
спектрограммы — следующий этап. Для него уже разделены независимая модель
`sys/luaplot/PlotModel.h`, отрисовка `PlotRenderer.cpp` и окно `PlotWindow.cpp`.

Пока нет 3D, логарифмических осей, анимации, Lua-обработчиков событий,
PDF/SVG, произвольных canvas-примитивов и полной совместимости с matplotlib.
Массивы должны быть плотными и содержать конечные числа (NaN/Inf отклоняются),
до миллиона числовых значений на фигуру. До 128 серий на axes, до 1000×1000
ячеек тепловой карты в пределах общего лимита. Легенда показывает до 8 серий.

## Проверки

`bash scripts/test-lua-plot.sh` проверяет экспорт, сигнатуру/размер PNG,
подграфики, неверные массивы, NaN, цвета, границы и DPI, восстановление после
ошибок. Включён в `build-windows.ps1 -Test`. Для отдельного EXE задайте
`PRAAT_EXECUTABLE`. `tests/lua-plot/lifecycle.lua` — GUI-проверка обновления,
закрытия и повторного открытия окна после освобождения Lua.
