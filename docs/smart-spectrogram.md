# SmartSpectrogram: спектры с произвольными временами кадров

SmartSpectrogram хранит дискретные мгновенные спектры в дБ. Времена кадров
задаются явно и могут идти с разным шагом. Частотная сетка общая для всех
кадров: начальная частота и шаг в Гц; число значений в каждом кадре одинаково.

По умолчанию каждый период показан своим исходным спектром, без смешивания
с соседними кадрами. В настройках можно включить Interpolate between frames:
тогда смешивается линейная мощность с переводом обратно в дБ. Через разрывы
между размеченными периодами смешивание и рисование не выполняются.
При уменьшении картинки сохраняется
максимум в частотной полосе каждой экранной строки. Это способ отображения;
исходные значения спектров в таблице не изменяются.
Для более слабых компонентов увеличьте Dynamic range в настройках
SmartSpectrogram (в совмещённом окне — Selected layers → SmartSpectrogram
display settings). Больший диапазон показывает больше слабых компонентов.

## Формат CSV/TSV

Для точного отображения пауз используйте вариант 2 с границами каждого
рассчитанного периода. Начало, середина и конец задаются в секундах:

```csv
# SmartSpectrogram 2
# frequency_start_hz=0
# frequency_step_hz=100
# values=db
# frame_start_s=0.10,0.30
# frame_end_s=0.12,0.32
time_s,0.11,0.31
-20,-30
-40,-50
```

Здесь спектр виден только на 0.10–0.12 и 0.30–0.32 с; между ними пустой фон.
В TSV списки границ разделяются табуляцией. Должно быть по одной паре границ
на кадр, границы не перекрываются и включают время кадра. Они сохраняются
в CSV/TSV и в текстовом/двоичном объекте Praat.

Файлы варианта 1 по-прежнему читаются, но содержат только середины кадров:
определить точные внутренние паузы по ним невозможно. Для G1 используйте
обновлённый скрипт или готовый cta0001-g1-periods.tsv с границами.
Вне диапазона времён кадров старый вариант больше не продолжается.

## Мгновенный спектр рассчитанного периода

- В отдельном редакторе: **SmartSpectrogram → Extract nearest period spectrum**.
- В совмещённом редакторе: **Selected layers → Extract nearest period spectrum**.
- В списке объектов выделите SmartSpectrogram и выберите
  **To Spectrum (nearest period)…**, указав время.

Используется курсор либо середина выделенного участка. Публикуется объект
Spectrum с исходными частотными отсчётами ближайшего рассчитанного кадра;
откройте его через View & Edit. Имя содержит фактическое время кадра.
Это работает и при курсоре в паузе; ближайший кадр выбирается по времени,
при равном расстоянии — более ранний. Смешивание и экранная нормировка
в извлечении не участвуют. Уровни дБ и частотная сетка сохраняются;
поскольку фаза в SmartSpectrogram не хранится, у Spectrum она нулевая.

## Совместимый формат 1

Файл в UTF-8. Перед таблицей идут четыре обязательные строки метаданных.
Первая строка самой таблицы содержит времена кадров в секундах; каждый
следующий ряд содержит значения одного частотного бина во всех кадрах.

```csv
# SmartSpectrogram 1
# frequency_start_hz=0
# frequency_step_hz=100
# values=db
time_s,0,0.2,0.7
-60,-50,-40
-30,-20,-10
-80,-70,-60
```

Здесь три кадра расположены в 0, 0,2 и 0,7 секунды. Три ряда спектра
соответствуют 0, 100 и 200 Гц. Значение при 0,2 с и 100 Гц равно −20 дБ.
Разделителем служит запятая либо табуляция; десятичный разделитель всегда
точка. Времена должны строго возрастать. Значения и метаданные должны быть
конечными числами; начало частот неотрицательно, шаг положителен. Импорт
проверяет одинаковую ширину рядов. Поддерживаются до 100 000 кадров, 100 000
бинов и 20 млн значений. ДБ здесь служат шкалой входных данных; абсолютная
акустическая калибровка файлом не задаётся.

В **Objects → Open → Read SmartSpectrogram from CSV/TSV...** выберите файл.
Объект сохраняется в обычном текстовом/бинарном формате Praat, а также обратно
в CSV/TSV. Пример: `tests/smart-spectrogram/irregular.csv`.

## Редактор и наложения

Выберите SmartSpectrogram и, если нужен звук, Sound, затем **View & Edit**.
Звуковая волна показывается в верхней части и воспроизводится командой Play. Времена
сопоставляются как абсолютные секунды: SmartSpectrogram должен целиком
лежать во временном диапазоне Sound.

При открытии вместе с Sound редактор показывает звуковую волну и стандартные
меню анализа Praat: **Pitch**, **Intensity**, **Formants** и **Pulses**.
Огибающая интенсивности, форманты, pitch и импульсы вычисляются из Sound;
фоном для них служит изображение SmartSpectrogram. Щелчок по нему показывает
частоту курсора в герцах, как в обычном редакторе звука. Без Sound можно
просматривать SmartSpectrogram и менять его значения, но вычислять эти
анализы не из чего.

Меню **SmartSpectrogram** содержит команды **Get frequency at frequency
cursor**, **Get value at cursor cross** (в дБ) и **Move frequency cursor to...**.
Запрос значения берёт время курсора или середину выделенного интервала и
частоту курсора; результат интерполируется по данным SmartSpectrogram.

При рисовании между двумя соседними кадрами используется линейная
интерполяция по **реальной временной дистанции**. На исходном времени кадра
показывается его точное значение. В меню **SmartSpectrogram → Display
settings...** можно задать верхнюю границу отображаемых частот в герцах,
динамический диапазон или выключить сглаживание. Значение 0 для верхней
границы показывает весь доступный диапазон. Если указанная граница выше
последнего частотного бина, показывается весь доступный диапазон. Настройка
частоты сохраняется в пользовательских настройках Praat и не удаляет данные
из SmartSpectrogram. Щелчок выбирает ближайшие кадр и частотный бин;
**Set selected value...** меняет значение с поддержкой Undo. Для скриптов
есть команда `Set value: frame, bin, dB` и запрос
`Get value at time and frequency: time, frequency` с интерполяцией по
времени и частоте.

Наложения привязываются к SmartSpectrogram по одному:

1. Выберите SmartSpectrogram вместе с Pitch и выполните **Attach Pitch**.
2. Выберите SmartSpectrogram вместе с Intensity и выполните **Attach Intensity**.
3. Выберите SmartSpectrogram вместе с FrequencyTrajectories и выполните
   **Attach FrequencyTrajectories**.

После привязки открывайте SmartSpectrogram отдельно или с Sound. Pitch и
частотные траектории рисуются по оси частот в Гц. Intensity — величина в дБ
по времени, поэтому она показана в подписанной верхней полосе спектра,
не меняя частотную ось. Привязка копирует объекты внутрь SmartSpectrogram;
они сохраняются в его родном формате Praat. Команда **Clear overlays**
удаляет все три копии. Экспорт CSV/TSV содержит только спектральную таблицу;
для сохранения наложений используйте родной формат Praat.

## Спектр по периодам G1 и траектории формант

Скрипт `scripts/g1-smart-spectrogram-formants.praat` читает звук и `seg_G1`.
В начале скрипта задайте пути к этим файлам и к выходному TSV. Интервал G1
с частотой `1 / длительность` выше 100 Гц повторяется до 2048 отсчётов.
Из полученного кадра скрипт вычисляет форманты методом Burg, затем применяет
окно Хэмминга, вычисляет спектр и записывает его в SmartSpectrogram. Временем
кадра и точек F1–F5 служит середина исходного периода. Значения формант
измеряются до применения окна Хэмминга; отсутствующие оценки пропускаются.

В Objects остаются Sound, TextGrid, SmartSpectrogram и FrequencyTrajectories.
Спектр и траектории также сохраняются в двух TSV, пути к которым указаны в
первых строках скрипта.
Выберите FrequencyTrajectories вместе со SmartSpectrogram и Sound и нажмите
**View & Edit**: сверху будет звуковая волна, снизу спектр с редактируемыми
траекториями формант. Можно выбрать только FrequencyTrajectories и
SmartSpectrogram для просмотра без звука или FrequencyTrajectories и Sound,
чтобы видеть траектории поверх обычной спектрограммы звука. В редакторе
траекторий меню **Trajectory → Spectrogram settings...** задаёт верхнюю
частоту и динамический диапазон изображения.

Интеграционный тест: `bash scripts/test-smart-spectrogram.sh` из MSYS2 CLANG64.
