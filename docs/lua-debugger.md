# Отладчик Lua Editor

В Windows-сборке Praat Custom откройте **Praat → New Lua script** или
**Open Lua script...**. Отладчик работает с Lua 5.5.1 непосредственно внутри
Praat и останавливается перед выполнением строки.

## Управление

| Действие | Клавиши / элемент |
| --- | --- |
| Поставить или снять точку останова | F9 на строке или щелчок в поле номеров строк |
| Запустить / продолжить до точки останова | F5, Continue |
| Приостановить работающий скрипт | F6, Debug → Pause |
| Выполнить строку с вызовом целиком | F10, Over |
| Войти в вызываемую Lua-функцию | F11, Into |
| Выйти из текущей функции | Shift+F11, Out |
| Прекратить запуск | Shift+F5, Stop |
| Удалить все точки | Debug → Remove All Breakpoints |
| Запустить без отладчика | Ctrl+R |

F10/F11 в состоянии покоя начинают новый запуск с остановкой на первой
исполняемой строке. Точка останова отмечается красным кружком; текущая строка —
стрелкой и жёлтым фоном. Ставьте точки на исполняемых строках: комментарии,
пустые строки и некоторые структурные строки не вызывают событие Lua.
При остановке внутри свёрнутого блока редактор автоматически раскрывает его.
Кнопки сворачивания остаются отдельной полосой справа от номеров.

## Панель

- **Variables**: локальные переменные текущего Lua-кадра, захваченные значения
  функции (upvalues), пользовательские глобальные значения.
- **Call Stack**: реальные кадры Lua, имена функций, исходные файлы и строки.
- **Output / Error**: ошибка Lua и последние 32 000 символов Praat Info.

После продолжения панель сохраняет последний снимок; статус показывает Running,
Finished, Stopped или Error. При ошибке сохраняются стек и доступные переменные,
открывается вкладка ошибки. Скрипт во время выполнения доступен только для чтения.

Инспекция не выполняет выражения и не вызывает `__tostring`, `__pairs` или иной
пользовательский код. Таблицы показывают до 8 элементов, вложенные таблицы —
маркером; строки ограничены 160 байтами, стек — 64 кадрами, локальные переменные —
128, upvalues и глобальные значения — по 64. Редактирования значений, Watch и
переключения выбранного кадра пока нет.

## Пример

Откройте `examples/lua-debugger-demo.lua` из поставки (в исходниках:
`tests/lua-debugger/demo.lua`). Поставьте точку на строке 6 и нажмите F5.
`value` равен 10. F11 переносит на строку 2 с `x = 10`; F10 — на строку 3
с `y = 11`; Shift+F11 — на строку 7 с `value = 11`. F5 завершает скрипт
с результатом 13 в Praat Info.

## Границы сеанса

Каждый запуск создаёт новое состояние Lua. Точки действуют в текущем буфере
редактора, следуют за правками текста через текстовые якоря и живут до закрытия
окна или смены уже назначенного пути файла. Условные точки и сохранение их
на диск пока не реализованы.

Шаги и точки поддерживают функции, рекурсию и корутины текущего файла. Другие
файлы (`require`) и нативные вызовы `praat.call`, `io`, `os` выполняются целиком:
пауза/остановка возможны после возврата к Lua текущего файла (Stop также
проверяется счётчиком инструкций). Это совместное выполнение в потоке GUI,
а не отдельный процесс. Выполненные команды Praat не откатываются при Stop.
Запуск выделения и командный запуск файла используют обычный режим без отладки.

## Проверки

`bash scripts/test-lua-debugger.sh` в MSYS2 CLANG64 собирает runner с настоящими
LuaRuntime и библиотеками Praat. Проверяет остановку перед строкой, Into/Over/Out,
рекурсию, повторные точки в цикле, корутины, инспекцию без метаметодов,
Stop/ошибку с повторным запуском и команды создания/анализа/удаления Sound.
Он включён в `build-windows.ps1 -Test`.

Регрессии: `test-lua.sh`, `test-folding.sh`, `test-trajectories.sh`,
`test-debugger.sh`. При проверке отдельного EXE задавайте `PRAAT_EXECUTABLE`.
Результаты и ручная проверка записаны в `project-docs/JOURNAL.md`.
