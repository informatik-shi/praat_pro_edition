# Разметка Sound + TextGrid со своими горячими клавишами

## Как открыть редактор

1. Загрузите Sound и TextGrid с разметкой. Если TextGrid ещё нет,
   выделите Sound и выполните **To TextGrid…**, задав названия уровней.
2. Выделите одновременно **Sound + TextGrid** и нажмите **View & Edit**.
   Это штатный редактор ручной разметки: можно добавлять и двигать границы,
   вводить подписи, выбирать уровни, слушать звук, показывать спектрограмму,
   Pitch, Intensity и форманты.
3. Откройте **TextGrid → Keyboard shortcuts…**.

Та же настройка доступна при редактировании TextGrid без звука и с LongSound.
Она относится именно к редактору TextGrid. Комбинированный просмотр
**View & Edit selected** с траекториями показывает TextGrid как справочный
слой; для изменения разметки используйте **Sound + TextGrid → View & Edit**.

## Окно настройки

- **Filter** ищет по названию меню или команды: например, `Boundary`,
  `interval`, `Play`, `Zoom`, `tier`.
- В списке показаны идентификатор `Меню/Команда` и текущее сочетание.
- Выберите команду. Под списком видны её штатная клавиша и текущее назначение.
- Введите сочетание в **New shortcut**, например `Ctrl+Enter`, `F4`,
  `Shift+F4`, `Ctrl+Shift+B`, `Alt+Right`, и нажмите **Assign**.
- **Disable** снимает сочетание с выбранной команды меню.
- **Default** возвращает этой команде штатное сочетание Praat.
- **Reload INI** перечитывает файл после ручного редактирования.
- **Close** закрывает окно настроек. Успешные назначения уже сохранены.

Изменения применяются сразу ко всем открытым редакторам TextGrid и
подхватываются при следующем запуске. В самих меню тоже меняются подписи
сочетаний. Если клавиша занята, окно показывает конфликтующую команду;
текущие настройки и файл остаются прежними. Сначала отключите прежнее
назначение либо выберите другое сочетание.

Поддерживаются буквы A–Z, цифры, F1–F12, Enter, Tab, Escape, Backspace,
Delete, Insert, Pause, Home, End, PageUp, PageDown, стрелки, Space и
модификаторы Ctrl, Shift, Alt. Для букв, цифр и Space нужен Ctrl или Alt,
чтобы оставалась возможность вводить подписи. Используются физические
буквенные клавиши Windows: названия сочетаний записываются латиницей.
Ctrl+A/C/X/V/Z и их варианты с Shift сохраняются для редактирования текста;
Alt+F4 и Alt+Space — для Windows. Штатные сочетания текстового поля продолжают
работать даже после отключения соответствующей команды меню.

Пример раскладки:

| Команда | Сочетание |
| --- | --- |
| Boundary / Add on selected tier | Ctrl+Enter |
| Boundary / Remove | Ctrl+Shift+Backspace |
| Play / Play or stop | F4 |
| Play / Play window | Shift+F4 |
| TextGrid / Select next interval | Alt+Right |
| TextGrid / Select previous interval | Alt+Left |

Вставка и удаление границ используют обычные операции Praat с историей Undo.
В этой раскладке F4 сначала освобождается у **Formants / Get fourth formant**.
Назначение горячей клавиши само по себе не меняет разметку. Сохраняйте
изменённый TextGrid обычной командой сохранения редактора.

## Отдельный INI

Файл **praat-textgrid-shortcuts.ini** находится рядом с запущенным EXE.
Путь показан в окне настройки. Это отдельный UTF-8 файл, не `praat-theme.ini`
и не стандартные Preferences Praat. При первом назначении он создаётся,
если отсутствует. Поставляемый шаблон оставляет штатные клавиши.

```ini
[TextGridEditor.Shortcuts]
Boundary/Add on selected tier=Ctrl+Enter
Boundary/Remove=Ctrl+Shift+Backspace
Formants/Get fourth formant=None
Play/Play or stop=F4
Play/Play window=Shift+F4
TextGrid/Select next interval=Alt+Right
TextGrid/Select previous interval=Alt+Left
```

Идентификатор копируйте из списка команд; он чувствителен к регистру.
Отсутствующая строка означает штатную настройку; `None` отключает сочетание.
Пустое значение тоже принимается как `None`. Комментарии начинаются с `;`
или `#`, поддерживаются BOM и CRLF. Сохранение из окна сохраняет комментарии,
прочие секции и неизвестные идентификаторы команд. Неизвестные команды
не выполняются: файл содержит только сопоставления с командами редактора.

Ошибочный файл не заменяется автоматически: при открытии редактора остаются
штатные настройки, а в окне настроек видна причина. Ошибка ручной перезагрузки
оставляет предыдущие действующие назначения. Если вновь открываемый редактор
имеет дополнительные команды и выявляет конфликт, он сохраняет свои штатные
клавиши; причина показана в настройках. Устраните конфликт и нажмите Reload INI. Запись идёт через временный
файл с заменой только после успешной проверки и записи.

Для другой папки можно задать переменную окружения
`PRAAT_TEXTGRID_SHORTCUTS_INI` до запуска Praat. Это также позволяет нескольким
сборкам пользоваться одним файлом. Для записи нужны права на выбранную папку.

## Проверки

`scripts/test-annotation-shortcuts.sh` проверяет разбор сочетаний, конфликты,
пустые и неверные значения, сохранение комментариев/неизвестных настроек,
возврат к defaults и повторное чтение. GUI-сценарий
`tests/annotation-shortcuts/gui.praat` проверяет назначения, конфликты,
сохранение/перезагрузку и открытие второго редактора. Проверки используют
отдельный INI в `.local-build`, пользовательский файл не меняется.
