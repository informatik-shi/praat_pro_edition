# Read SEG files → TextGrid

Команда **Objects → Open → Read SEG files...** читает разметку SpeechTechn
и создаёт один TextGrid. Python для импорта не нужен.

## Параметры

- **SEG file path**: выберите один существующий файл, например `record.seg_B1`.
  Команда ищет файлы с тем же базовым именем (`record`) в той же папке.
- **Levels (empty = all except G1)**: пустое поле, `*` или `all` — все найденные
  SEG-уровни, кроме G1. Чтобы прочитать часть уровней, введите `B1 R1` или
  `seg_B1, seg_R1`. Допустимы пробелы, запятые и точки с запятой.
- **Encoding**: по умолчанию **UTF-8**. Доступны Windows-1251, UTF-16LE,
  UTF-16BE, KOI8-R, CP866, ISO-8859-1. Кодировка применяется ко всем выбранным
  файлам этой операции; общие настройки чтения текста Praat не меняются.
  Для смешанных кодировок используйте отдельные операции импорта.

**G1 читается только при явном указании в Levels:** `G1`, `B1 G1` или `* G1`.
Выбор файла `record.seg_G1` в качестве начального сам по себе не включает G1.
Повреждённый G1 не мешает читать остальные уровни, если G1 не выбран.

`record.seg_B1` становится уровнем **B1**, `record.seg_R1` — **R1**.
Все уровни имеют тип **IntervalTier**, включая явно выбранный G1.
Названия сохраняют регистр расширения файла. Выбор уровней нечувствителен
к регистру, повторные имена не дублируют уровень. При явном списке порядок
уровней совпадает со списком; при автоматическом выборе имена сортируются.
Поддерживаются и расширения за пределами исходного набора B/R/Y/G1–4.
Отсутствующий явно запрошенный уровень вызывает ошибку.

## Примеры

Praat Script:

```praat
# UTF-8; все соседние уровни, кроме G1
Read SEG files: "C:/data/record.seg_B1", "", "UTF-8"
# Только два уровня из старых файлов SpeechTechn
Read SEG files: "C:/data/record.seg_B1", "B1 R1", "Windows-1251"
# Все уровни, включая G1
Read SEG files: "C:/data/record.seg_B1", "* G1", "UTF-8"
Save as text file: "C:/data/record.TextGrid"
```

Lua:

```lua
local grid = praat.call("Read SEG files",
    "C:/data/record.seg_B1", "B1 R1", "UTF-8")
praat.select(grid)
praat.call("Save as text file", "C:/data/record.TextGrid")
```

## Формат и преобразование

Изучены `SpeechTechn/SegReader.py`, `SegDict.py`, `DescriptorReader.py`
и `DescriptorWriter.py` из предоставленной папки Laboratory_v_5_02.
Их исходное чтение/запись использует Windows-1251; для таких файлов выбирайте
эту кодировку явно. В новой команде по запросу пользователя начальный выбор — UTF-8.

```text
[PARAMETERS]
SAMPLING_FREQ=1000
BYTE_PER_SAMPLE=2
CODE=0
N_CHANNEL=1
N_LABEL=3
[LABELS]
0,2,первый интервал
1000,2,второй интервал
2000,2,
```

Результат: интервалы `[0, 0.5]` и `[0.5, 1.0]` секунды. Первая колонка —
позиция в байтах. Как в Python, сначала берётся целая часть деления позиции
на BYTE_PER_SAMPLE, затем результат делится на SAMPLING_FREQ. N_CHANNEL
не является дополнительным делителем. Вторая колонка — тип/цвет метки;
имя уровня берётся из расширения, а не из этой колонки. Запятые после второй
запятой принадлежат тексту метки.

Текст метки относится к промежутку до следующей метки. Последняя метка —
закрывающая граница, её текст не создаёт отдельный интервал. Нужны минимум
две границы. Диапазон TextGrid — от 0 до самой поздней последней границы
среди выбранных уровней. До первой границы и после конца более короткого
уровня создаются пустые интервалы. Звуковой файл не читается и его длительность
не используется.

UTF-8 и UTF-16 допускают BOM; для UTF-16 выберите правильный порядок байтов.
Невалидные Unicode-последовательности, NUL, неверные заголовки, несовпадение
N_LABEL, отрицательные/переполненные числа и непоследовательные границы
вызывают ошибку с именем файла и строкой. В отличие от Python-читалки,
повторные и обратные границы не отбрасываются молча. При ошибке частичный
TextGrid не появляется. Корректная последовательность байтов в неверно выбранной
однобайтной кодировке может дать неверный текст: автоматического определения нет.

## Проверка

Синтетические тесты находятся в `tests/seg/`; исходные файлы пользователя
не копируются в репозиторий. Для восстановления fixtures используется
`python tests/seg/make-fixtures.py`. Проверка собранного EXE в MSYS2:

```bash
PRAAT_EXECUTABLE=./.local-build/Praat-seg-x64.exe bash scripts/test-seg.sh
```

Проверяются выбор/исключение G1, несколько уровней и их порядок, типы IntervalTier,
времена и пустые интервалы, TextGrid roundtrip, все семь кодировок, BOM,
символы вне BMP, ошибки формата и отсутствие частичных объектов при ошибке.
