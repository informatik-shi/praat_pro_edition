# Тёмная тема и цвета Praat Pro Edition

## Быстрый запуск

Запустите `praat-pro-dark-x64.exe`. Рядом с EXE лежит `praat-theme.ini`.
Редактируйте этот файл обычным текстовым редактором и **перезапустите Praat**.
Уже открытый экземпляр сохраняет палитру, которую прочитал при запуске.
Отсутствующий INI означает встроенную тёмную палитру.

Цвет записывается как `#RRGGBB`, например `#73D7E8`. Файл — UTF-8.
Строки комментариев начинаются с `;` или `#`; после значения можно добавить
комментарий через `;`. Имена секций и ключей не зависят от регистра.
Отсутствующие ключи берутся из базовой палитры. Неверный цвет или неизвестный
ключ пропускается; диагностическое сообщение направляется в Windows Debug Output.
Последнее корректное повторное значение ключа имеет приоритет.

## Пример своей палитры

```ini
[theme]
enabled=true
base=dark

[window]
background=#20242B
text=#E5E9F0
control_background=#2C323C
border=#546174
selection=#365B80
selection_text=#FFFFFF

[editor]
background=#181C22
text=#E5E9F0
gutter=#242A33
line_number=#9AA8BA
breakpoint=#FF6B7A
execution=#514323
error=#FF6B7A

[analysis]
background=#14191F
text=#DCE5F0
waveform=#73D7E8
waveform_selected=#FFC078
frame=#557487
cursor=#FF7B8B
selection=#334D6B
pitch=#82AAFF
pitch_secondary=#B6CAFF
intensity=#A9DB70
formants=#FF8177
formants_secondary=#F4B4CC
spectrum=#C7E99B
pulses=#8795A8

[spectrogram]
background=#14191F
foreground=#BACBD9

[trajectory]
f1=#FF89CF
f2=#65D6E8
f3=#FF9C75
f4=#9EACFF
f5=#C8DF80
```

`window` задаёт цвета главного окна, диалогов, списков, кнопок и меню.
`editor` относится к редакторам Praat и Lua, номерам строк и отладчику.
`analysis` управляет фоном и цветами графиков в стандартном Sound Editor,
общем редакторе выбранных слоёв и редакторах спектра/SmartSpectrogram.
`waveform_selected` — акцент выбранного значения амплитуды;
`selection` — наложение выделенного временного участка.
`pitch_secondary` — широкий нижний штрих Pitch. `formants_secondary` —
второй цвет точек штатного анализа формант.

Два цвета `spectrogram` задают шкалу **серой** спектрограммы:
`background` для слабых значений, `foreground` для сильных. Тема действует
на вычисленный Spectrogram и SmartSpectrogram. Настройки диапазона дБ,
предыскажения, инверсии и интерполяции продолжают работать. Паузы вне
рассчитанных периодов SmartSpectrogram остаются пустыми.
Другие штатные цветовые карты, например Viridis, сохраняют свою шкалу.

`trajectory.f1`…`trajectory.f10` — цвета дорожек по порядку в
FrequencyTrajectories; после десятой палитра повторяется. Это цвета
объекта траекторий, независимо от штатного анализа из меню Formants.

## Подсветка кода

В секции `[syntax]` доступны:

| Ключ | Что окрашивается |
| --- | --- |
| keyword | Ключевые слова Praat и Lua |
| form | Объявления формы Praat |
| comment | Комментарии |
| string | Строки |
| number | Числа |
| string_variable | Строковые переменные Praat |
| array | Массивы Praat |
| function | Функции Praat и встроенные имена Lua |
| procedure | Процедуры Praat |
| command | Команды Praat |

Оба редактора используют общую палитру; выполнение, точки останова,
сворачивание кода и диагностика продолжают работать.

## Светлая тема и возврат к исходному виду

Для встроенной светлой палитры используйте отдельный минимальный файл
`praat-theme-light.ini` из комплекта либо оставьте в своём INI только:

```ini
[theme]
enabled=true
base=light
```

Параметр `base` задаёт исходные значения: явно прописанные цвета других
секций по-прежнему имеют приоритет. Поэтому смена одного `base=light`
в полном тёмном INI не отменяет оставшиеся тёмные цвета.

Для прежнего интерфейса без применения нашей палитры:

```ini
[theme]
enabled=false
```

Можно выбрать другой файл через переменную окружения `PRAAT_THEME_INI`
с абсолютным путём. Она имеет приоритет над INI рядом с EXE и позволяет
запускать отдельные экземпляры с разными палитрами. Файл автоматически
не перезаписывается.

## Область действия

Тема меняет интерфейс и экранные графики редакторов. Численные данные,
TSV, аудиофайлы и настройки анализа не меняются. Окно Picture и экспорт
научных рисунков используют прежние цвета: тёмная тема интерфейса
не превращает экспорт в тёмный рисунок. Lua-графики сохраняют цвета,
которые пользователь явно указал в своём скрипте.

Системные панели выбора файлов и полосы прокрутки могут сохранять оформление
Windows. Цвет заголовка поддерживается там, где это позволяет Windows;
старые системы игнорируют неподдерживаемые атрибуты. Поставляемый EXE — x64;
новая сборка x86 для Windows 7 в этой задаче не создавалась.

## Проверки разработчиком

`scripts/test-theme.sh` проверяет чтение INI, UTF-8 BOM, CRLF, регистр,
неверные значения, дубликаты, отключение и смешивание цветов спектра.
Сценарий `tests/theme/gui.praat` открывает общий редактор с волной,
SmartSpectrogram, обычной спектрограммой и траекториями, а также Spectrum.
