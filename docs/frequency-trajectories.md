# Траектории частот поверх спектрограммы

Новый объект **FrequencyTrajectories** хранит несколько именованных траекторий.
Каждая точка содержит время в секундах и частоту в Гц. Звук хранится отдельно:
перемещение точек исправляет разметку, а не звуковые отсчёты.

## Начало работы

1. Откройте WAV обычной командой **Open → Read from file**.
2. Выберите **Open → Read frequency trajectories from CSV/TSV...**.
3. В Objects выделите одновременно Sound и FrequencyTrajectories (Ctrl+клик).
4. Нажмите **View & Edit**. Сверху показана волна, снизу — спектрограмма и точки.
5. Перетаскивайте точку мышью: горизонтально меняется время, вертикально — частота.
   Щелчок рядом с точкой другой линии выбирает эту траекторию автоматически.
6. **Edit → Undo** отменяет исправление. Штатные zoom и playback позволяют
   рассмотреть и прослушать выделенный интервал.
7. В Objects выберите FrequencyTrajectories и **Save as CSV file...** либо
   **Save as TSV file...**. Сохранить исправления нужно явно.

Можно создать пустой объект через **New → Create FrequencyTrajectories...**
или преобразовать результат анализа Formant командой **To FrequencyTrajectories**.
Без выбранного Sound открывается редактор траекторий без спектрограммы/аудио.

## Формат CSV / TSV

UTF-8, первая строка обязательна:

```csv
time_s,track,frequency_hz
0.000,F1,500
0.100,F1,530
0.200,F1,560
0.000,F2,1500
0.100,F2,1480
0.200,F2,1460
```

Для TSV используйте табуляцию вместо запятой. Допускается имя первой колонки
`time` вместо `time_s`. Десятичный разделитель — точка. Порядок строк произвольный;
имена траекторий нумеруются по первому появлению. Поддерживаются кириллица,
CSV-кавычки и удвоенные кавычки внутри имени. Переносы строк внутри имени запрещены.

Время должно быть конечным числом, частота — конечной и неотрицательной.
В одной траектории не может быть двух точек с одинаковым временем.
Максимум 256 траекторий, имя до 256 символов. Пустые строки игнорируются.
Повреждённый импорт не создаёт частично заполненный объект.

Временная область CSV определяется первой/последней точкой среди всех траекторий.
Для единственного времени добавляется по 0,5 с с обеих сторон. Чтобы открыть
вместе со звуком, область объекта должна лежать внутри времени Sound; скрытого
смещения или растяжения нет. При необходимости подготовьте времена относительно
начала вашего аудиофайла. CSV сохраняет точки, но не пустые траектории и не
дополнительные границы времени: для точного сохранения всего объекта используйте
штатный **Save as text file** или **Save as binary file** Praat.

## Управление

- **Trajectory → Select trajectory...** — выбор по номеру; имя активной линии
  показано в легенде. **Ctrl+N** — следующая линия.
- **Ctrl+T** — добавить точку в позиции курсора; **Add point at...** — точные числа.
- **Remove point(s)** — удалить ближайшую точку или точки выделенного интервала.
- Shift+перетаскивание точки внутри выделенного интервала двигает группу,
  используя штатные правила RealTier Praat. Пересечение соседних точек запрещено.
- **Spectrogram settings...** — верхняя частота, длина окна, динамический диапазон.
  По умолчанию: 5500 Гц, 0,005 с, 50 дБ. Для более узких частотных полос можно
  увеличить окно до 0,025–0,04 с. Частоты выше текущей шкалы остаются в объекте.

Редактор воспроизводит копию исходного Sound. Изменение Sound в другом окне
не обновляет эту копию: откройте редактор заново. Это соответствует обычным
редакторам tiers в Praat. Никакой ресинтез звука по исправленным линиям не выполняется.
Линии интерполируются линейно; значения активного tier за крайними точками
показываются с постоянным продолжением по штатным правилам RealTier.

## Архитектура

- `fon/FrequencyTrajectories*`: Function + коллекция RealTier, имена,
  стандартная сериализация Praat, импорт/экспорт, проверка данных.
- `fon/praat_FrequencyTrajectories.cpp`: меню Objects, запросы, команды,
  преобразование Formant. Исходный Formant не меняется.
- `foned/FrequencyTrajectoriesEditor*`: FunctionEditor, SoundArea и наследник
  RealTierArea. Используется настоящий Undo/Redo и broadcastDataChanged Praat.
- Спектрограмма вычисляется Sound_to_Spectrogram_e для видимого интервала с
  запасом окна. Кэш зависит от интервала и настроек, но не от положения точек.
  Сетка ограничивается примерно 1500 временными и 600 частотными отсчётами;
  увеличьте масштаб для подробного анализа. Короткий/неподходящий интервал
  показывает сообщение, если вычислить спектрограмму невозможно.
- Алгоритмы Sound, Formant и существующий Script IDE не изменены.

Примеры: `tests/trajectories/tracks.csv`, `demo.praat`.
Тесты: `bash scripts/test-trajectories.sh` из MSYS2 CLANG64.
