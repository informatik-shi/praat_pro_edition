# Пробный скрипт: периоды G1 → SmartSpectrogram

Скрипт `scripts/g1-period-smart-preview.praat` предназначен для проверки
алгоритма перед добавлением команды в меню Pro.

## Запуск

1. Запустите нашу сборку Praat с поддержкой SEG и SmartSpectrogram.
2. Выберите **Praat → Open Praat script…**, откройте скрипт и выполните **Run → Run**.
3. В форме укажите аудиозапись, соответствующий файл `.seg_G1` и новый путь
   результата `.tsv`. Существующий файл результата не перезаписывается.
4. Оставьте **Repeat duration s = 5**. Порог частоты по умолчанию — 100 Гц,
   верхняя частота спектра — 5000 Гц. Для `.sbl` используется 22050 Гц;
   для WAV и других звуковых файлов — частота из самого файла.
   Дополнительные параметры соответствуют ручному примеру: **Analysis window s = 1**,
   **Requested time step s = 0.002**, **Requested frequency step hz = 20**,
   **Slice time s = 1**. Форма окна — Gaussian.
5. После обработки выделены исходный Sound и полученный SmartSpectrogram.
   Нажмите **View & Edit**. TSV также можно открыть через
   **Open → Read SmartSpectrogram from CSV/TSV…**.

При запросе Praat на разрешение сохранить результат разрешите запись
в выбранный вами файл. Проверенный локальный запуск из консоли использует
`--FULL-TRUST`; это разрешение нужно для записи TSV.

## Алгоритм

Каждый интервал G1 рассматривается как отдельный период. Для него
вычисляется `f = 1 / T`, где T задан в секундах. Принимаются только
положительные интервалы внутри звука с частотой **строго больше 100 Гц**
(при стандартном пороге). Ровно 100 Гц не включается.

Отсчёты выбранного канала периода циклически повторяются до пяти секунд.
Последнее повторение обрезается до требуемого числа отсчётов. Создаётся
спектрограмма командой `To Spectrogram: 1, 5000, 0.002, 20, "Gaussian"`,
затем срез `To Spectrum (slice): 1`, как в ручном примере пользователя.
Параметры окна, обоих шагов и времени среза доступны в форме запуска.
Gaussian в Praat использует участок длительностью вдвое больше номинального
окна, поэтому пятисекундного звука достаточно для окна 1 с.
Его значения переводятся в дБ штатным преобразованием Praat
`To Ltas (1-to-1)`. Неопределённые и слишком малые значения ограничиваются
порогом **Minimum db**, по умолчанию −160 дБ.

Этот срез становится одним кадром SmartSpectrogram, расположенным в середине
исходного интервала G1. Частотная сетка общая для всех кадров. TSV варианта 2
содержит начало и конец каждого принятого периода: спектр показан только
на этих участках. Пропущенные периоды и паузы остаются пустыми.
По умолчанию кадры отображаются без смешивания. Для выполнения скрипта
и чтения такого TSV нужна новая сборка с поддержкой границ периодов.

G1 читается существующим импортёром SEG как IntervalTier. Время и интервалы
совпадают с результатом `Read seg files` для уровня G1. Разметка должна
соответствовать выбранному звуку. Для многоканального звука укажите номер
канала; по умолчанию анализируется первый.

## Что проверить

Если **Keep example objects = yes**, для первого принятого периода остаются:

- `g1_repeated_example` — повторённый пятисекундный звук;
- `g1_spectrogram_example` — его спектрограмма;
- `g1_spectrum_slice_example` — спектральный срез на заданном времени
  повторённого звука (по умолчанию 1 с).

Их можно открыть отдельно и сравнить с первым кадром SmartSpectrogram.
В Info выводятся число интервалов, число принятых периодов, фактическая длина
повторения и параметры частотной сетки.

Длительность повторения и длина анализирующего окна — разные параметры.
Плотность частотной сетки определяется также запрошенным шагом частоты.
Praat корректирует фактическую сетку под FFT: при 22050 Гц и стандартных
параметрах получаются 251 отсчёт, начало 9.757232666 Гц, шаг 19.850921631 Гц.
В TSV записываются именно фактические начало и шаг, а не условные 0 и 20 Гц.
Действует существующее ограничение SmartSpectrogram — 20 миллионов значений.
При его превышении скрипт сообщает об этом; увеличьте шаг частоты
либо уменьшите верхнюю частоту. Изменения выбранного порога и длительности
делаются в форме запуска, редактировать исходник для этого не нужно.

## Проверка разработчиком

Синтетический сигнал 200 Гц и разметка с периодами 200, 200, 100 и 50 Гц:
приняты два кадра на временах 0.0025 и 0.0075 с; в обоих кадрах одинаковое
число частотных отсчётов. Спектральный уровень на 200 Гц превышает уровень
на 1000 Гц более чем на 20 дБ. Проверка выполняется файлом
`tests/smart-spectrogram/g1-preview.praat` с новым абсолютным префиксом
временных файлов в качестве аргумента.

На реальной записи cta0001 из 134 интервалов принято 130. Получено 251
частотных отсчётов на кадр с шагом около 19.85092 Гц. TSV прошёл проверку
на общую сетку, возрастающие времена и конечные числовые значения.

Для периода из ручного примера 0.776689–0.783673 с выполнена независимая
проверка: фактические копии Sound объединены через Concatenate, обрезаны до
5 с, затем применены указанные команды Gaussian и среза на 1 с. Все 251
значение дБ совпало с кадром SmartSpectrogram: максимальная ошибка 0 дБ.
Проверка: `tests/smart-spectrogram/g1-manual-reference.praat`.

Предыдущий вариант использовал Hamming почти на всю длину пятисекундного
звука. Он проверял другой способ спектрального анализа. Для сравнения с
ручным примером используйте обновлённый файл
`dist/examples/g1-period-smart-gaussian.praat`; старый открытый редактор
Praat автоматически содержимое с диска не перечитывает.
