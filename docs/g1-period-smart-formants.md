# Периоды G1 → SmartSpectrogram и форманты F1–F5

Скрипт `g1-period-smart-formants.praat` расширяет последнюю версию
`g1-period-smart-preview.praat`. Спектры рассчитываются прежним способом;
дополнительно из каждого размноженного периода получаются форманты Burg.
Результат — объект **FrequencyTrajectories** с дорожками **F1–F5**.

## Как запустить

1. Используйте сборку `dist/praat-pro-smart-periods-x64.exe` или актуальную
   `dist/praat-custom.exe`: требуется поддержка SmartSpectrogram с границами кадров.
2. **Praat → Open Praat script…** → `dist/examples/g1-period-smart-formants.praat`.
3. Нажмите **Run → Run**. Укажите исходный звук, его `.seg_G1`, новый путь
   **Smart tsv file** и отдельный новый путь **Formants tsv file**.
   Папки должны существовать. Существующие результаты не перезаписываются.
4. Для первой проверки оставьте остальные параметры по умолчанию.
   Если Praat запрашивает разрешение записать результат, разрешите запись
   выбранных файлов.
5. После завершения уже выделены Sound, SmartSpectrogram,
   FrequencyTrajectories и обычный Spectrogram. Нажмите **View & Edit selected**.

Для `.sbl` скрипт читает 16-bit Little Endian и устанавливает частоту
**Raw sampling frequency** — по умолчанию 22050 Гц. Для WAV используется
частота самого файла. **Channel** выбирает канал для анализа периодов.
**Seg encoding** по умолчанию UTF-8; при необходимости укажите Windows-1251.

## Что именно вычисляется

Каждый интервал G1 считается отдельным периодом. Принимаются периоды внутри
звука с частотой `1 / длительность` **строго выше Minimum pitch hz**
(по умолчанию 100 Гц). Период должен содержать хотя бы два отсчёта.
Его отсчёты циклически повторяются до **Repeat duration s = 5** секунд.

Из этого звука получаются два независимых результата:

- **Спектр периода:** Gaussian-спектрограмма с окном 1 с, верхней частотой
  5000 Гц, запрошенными шагами 0.002 с / 20 Гц; срез на 1 с,
  перевод в дБ через `To Ltas (1-to-1)`. Фактическая частотная сетка
  сохраняется в SmartSpectrogram, как в предыдущем скрипте.
- **Форманты:** `To Formant (burg)` применяется к размноженному Sound.
  F1–F5 измеряются в середине этого звука — при пяти секундах это 2.5 с.
  Для каждой форманты создаётся точка в середине соответствующего периода
  **исходной записи**. Во временной шкале траекторий нет пятисекундных вставок.

Разметка точных начала и конца периода сохраняется в SmartSpectrogram 2:
фон отсутствует там, где нет принятого периода. В траектории записываются
только определившиеся положительные значения. Если Burg не определил F5,
точка F5 для этого периода пропускается; нули не подставляются.
Линии FrequencyTrajectories соединяют соседние существующие точки,
в том числе через пропуски измерений.

## Настройки формант

| Поле | По умолчанию | Назначение |
| --- | --- | --- |
| Number of formants | 5 | Число дорожек F1…Fn, максимум 10 |
| Formant ceiling hz | 5500 | Верхняя граница Burg; не выше половины частоты дискретизации |
| Formant window s | 0.025 | Окно анализа формант |
| Formant time step s | 0.01 | Шаг анализа формант |
| Formant preemphasis hz | 50 | Начальная частота предыскажения |

Burg даёт оценки резонансов, которые нужно проверять по звуку и спектру;
пять формант не гарантируются для каждого периода. Подбор верхней границы
и окна влияет на результат. При потолке Burg 5500 Гц отдельные точки могут
быть выше отображаемого по умолчанию спектрального диапазона 5000 Гц:
увеличьте частотный диапазон отображения либо выберите другой потолок анализа.

**Create regular spectrogram** создаёт обычный Spectrogram из исходного Sound
с Gaussian-окном **Regular window s = 0.005**, шагами 0.002 с / 20 Гц.
В многоканальной записи эта обычная спектрограмма использует штатное сведение
каналов Praat; анализ периодов использует выбранный Channel.

## Совместный просмотр и правка

Начальный фон общего редактора — SmartSpectrogram. Меню **Selected layers**
переключает его на выбранный обычный Spectrogram и обратно. Траектории
остаются поверх фона; доступны штатные Pitch, Intensity, Formants и Pulses.
Меню **Formants** показывает отдельный штатный анализ исходного звука;
дорожки F1–F5 этого скрипта хранятся в FrequencyTrajectories.

Щелчок по точке показывает частоту в герцах, перетаскивание меняет точку.
После ручной правки сохраните FrequencyTrajectories заново из окна Objects.
**Selected layers → Extract nearest period spectrum** извлекает спектр
ближайшего рассчитанного периода, в том числе если курсор стоит в паузе.

При включённом **Keep example objects** остаются Sound, Spectrogram,
Spectrum и Formant первого принятого периода для независимой проверки.
Их имена заканчиваются на `_example`.

## Файлы результата

Для пути формант `result.tsv` сохраняются:

- `result.tsv` — переносимая таблица `time_s`, `track`, `frequency_hz`.
- `result.tsv.FrequencyTrajectories` — нативный объект с полным набором
  дорожек, даже если некоторые остались пустыми. Открывается через
  **Open → Read from file…**.
- `result.tsv.measurements.tsv` — по строке на принятый период: его середина,
  начало, конец и значения F1…F5. Неопределённые значения — пустые ячейки.

SmartSpectrogram сохраняется по отдельному пути **Smart tsv file**.
Его можно открыть через **Read SmartSpectrogram from CSV/TSV…**;
таблицу траекторий — через **Read frequency trajectories from CSV/TSV…**.

## Проверки

`tests/smart-spectrogram/g1-formants.praat` создаёт синтетический звук
с разными периодами 200 и 250 Гц, а также интервалами 100 и 50 Гц.
Принимаются ровно два периода. Проверяются выбранные объекты, совпадение
всех пяти формант второго периода с отдельным расчётом Burg и сохранение
нативных траекторий. Проверка — PASS.

На cta0001: из 134 интервалов принято 130, по 251 частотному отсчёту;
F1–F4 имеют по 130 точек, F5 — 40. Все времена совпадают с серединами
кадров SmartSpectrogram; неопределённые значения не заменены числами.
