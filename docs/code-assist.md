# Подсказки кода в редакторах Lua и Praat

В Windows-сборке оба редактора имеют меню **Code**. Установка Python,
Node.js и внешнего сервера подсказок не требуется.

## Автодополнение

Наберите начало имени и нажмите **Ctrl+Space**. Стрелки выбирают вариант,
**Enter** или **Tab** вставляют его, **Esc** закрывает список. Вставку можно
отменить обычным Undo. В Lua список также появляется после точки.

- Lua: ключевые слова, распространённые функции `math`, `string`, `table`,
  `lfs`, API `praat`, идентификаторы из текущего документа.
- Praat: ключевые слова, основные встроенные функции, идентификаторы документа.
- Названия команд берутся из реестра текущей сборки Praat. В Lua они
  предлагаются внутри первого строкового аргумента `praat.call`;
  в Praat — в начале команды, начинающейся с заглавной буквы.

Примеры: `math.s`, `praat.ca`, `praat.call("To Spe` в Lua;
`To Spe` и `Read seg` в Praat. Регистр букв имеет значение.
Список ограничен 200 вариантами; уточните начало имени для более узкого поиска.

Это лексическое дополнение: найденное в документе имя не обязательно доступно
в текущей области видимости. Анализ типов таблиц, импорта модулей и других
файлов пока не выполняется. Библиотеки и команды ради подсказок не запускаются.

## Параметры

**Ctrl+Shift+Space**, либо **Code → Parameter hints**, показывает подсказку
для текущего вызова. Она также появляется при вводе `(` и `,` в Lua или `:`
и `,` в Praat, если вызов распознан. Esc закрывает окно.

Для команд показывается требуемый класс выбранных объектов. Полные подписи
параметров пока заданы для `To Spectrogram`, `Create Sound from formula`,
`Read from file`, API `praat` и части стандартных функций Lua. Для объявленных
в документе функций Lua и процедур Praat используется текст объявления.
Подсказка не выделяет активный аргумент и не проверяет его тип.

## Ошибки

Проверка начинается через 400 мс после последнего изменения. Она работает
в отдельном потоке, на копии текста, без исполнения кода. Устаревшие результаты
не применяются. Для документов более 1 000 000 символов автоматическая
проверка отключается с сообщением в списке проблем.

- **Lua:** проверка компилятором той же встроенной версии Lua, что выполняет
  скрипты. Показывается первая синтаксическая ошибка.
- **Praat:** начальная проверка пар блоков `if/endif`, `for/endfor`,
  `while/endwhile`, `repeat/until`, `procedure/endproc`, `form/endform`,
  а также расположения `else/elsif`. Выражения и аргументы команд не проверяются.
  При наличии `include` проверка блоков пропускается: подключённый файл может
  содержать их продолжение. Отсутствие сообщений не гарантирует корректность скрипта.

Проблемные строки подчёркиваются красным. **Code → Show code problems**
открывает обновляемый список. Двойной щелчок переносит на строку.
**F4** переходит к следующей проблеме. При переходе раскрываются свёрнутые
блоки. Подчёркивание — слой рисования, оно не меняет текст, сохранение и Undo.

## Отладка

Существующая отладка работает независимо от проверки:
**F9** — точка останова, **F5** — запуск/продолжение,
**F10** — шаг с обходом, **F11** — шаг с заходом,
**Shift+F5** — остановка. Панели Variables и Call Stack показывают состояние
при остановке. Ошибки выполнения отображаются в Output / Error;
переход к строке выполняется существующим отладчиком.

Во время выполнения подсказки и проверка приостановлены, исходник остаётся
защищённым от редактирования. Для выявления ошибок, зависящих от выбранных
объектов, файлов и данных, используйте отладку.

## Проверки разработки

`scripts/test-code-assist.sh` проверяет модель дополнения и структуру Praat.
`scripts/test-code-assist-editors.sh` проверяет настоящие Windows-редакторы:
вставку и Undo, обновление диагностики, подсказки параметров и переход к
ошибке внутри свёрнутого блока. Эта проверка создаёт собственные временные
редакторы и не вводит клавиши в пользовательские окна.
