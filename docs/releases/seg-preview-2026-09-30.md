# Praat Pro Edition 7.0.02 — SEG import preview 2

В этой сборке добавлена команда **Objects → Open → Read SEG files...**.
Она собирает файлы `record.seg_B1`, `record.seg_R1` и другие файлы
с тем же базовым именем в TextGrid. Имена уровней — B1, R1 и так далее;
все уровни имеют тип IntervalTier.

Пустой список уровней загружает все найденные файлы, кроме G1.
Укажите `G1` явно, если он нужен. Можно загрузить только выбранные уровни,
например `B1 R1`. Кодировка выбирается при импорте; по умолчанию UTF-8.
Доступны также Windows-1251, UTF-16LE, UTF-16BE, KOI8-R, CP866 и ISO-8859-1.

Скачайте **praat-seg-x64.exe** для Windows 10/11 x64 или
**praat-seg-win7-x86.exe** для Windows 7 SP1 x86. Запустите новый файл:
ранее опубликованный `praat-windows-x64.exe` не содержит команду SEG.
Оставьте старое окно открытым, если в нём есть несохранённые объекты;
новую сборку можно запустить отдельно.

`praat-seg-windows.zip` содержит оба EXE, руководство, лицензии и примеры.
Соответствующие исходники — в `praat-seg-source.zip` и в ветке `develop`.
SHA-256 всех файлов указан в `SHA256SUMS.txt`.

Импорт SEG и выбор кодировки прошли автоматические тесты на x64 и x86.
Запуск именно на физическом ASUS Eee PC 1025C / Windows 7 SP1 всё ещё
требует проверки на устройстве, поэтому выпуск предварительный.
