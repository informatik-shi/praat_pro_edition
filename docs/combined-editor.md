# Общий редактор выделенных объектов

Выделите в окне Objects один **Sound** и один **FrequencyTrajectories**.
Дополнительно можно выделить по одному **TextGrid**, **SmartSpectrogram** и
обычному **Spectrogram**. Нажмите **View & Edit selected** в списке команд или
выберите **Pro → View & Edit selected**. Все пять объектов можно выделить
одновременно.

Окно построено на обычном редакторе Sound. Звук можно редактировать и
воспроизводить; доступны его стандартные меню и функции анализа: обычная
спектрограмма, Pitch, Intensity, Formants и Pulses. TextGrid показывается в
синхронной полосе под анализом как справочная разметка. Частотные траектории
рисуются поверх спектрограммы; точку можно перетащить мышью. Изменение
сохраняется в исходном объекте FrequencyTrajectories, пока открыто окно.
Соседние точки нельзя переставлять по времени друг через друга.
Щелчок по точке ставит частотный курсор на её точное значение; название
траектории и частота в герцах показываются в подписи спектра.

Если одновременно выделены SmartSpectrogram и Spectrogram, начальным фоном
будет SmartSpectrogram. В меню **Selected layers** можно переключить фон на
обычный Spectrogram и обратно. Это не меняет сами объекты. Если не выбран ни
один из них, остаётся вычисляемая Praat спектрограмма звука. Кнопки в меню
**Spectrogram** управляют показом фона; остальные стандартные меню анализа
продолжают работать.

Для SmartSpectrogram используйте **Selected layers → SmartSpectrogram display
settings...**: границы частот и динамический диапазон применяются сразу.
Обычный выбранный Spectrogram использует настройки отображения из меню
**Spectrogram**. Изменение длины окна анализа не пересчитывает уже загруженный
SmartSpectrogram: его кадры и значения заданы исходным файлом.

TextGrid в этом общем окне служит для просмотра и выбора времени; редактировать
его интервалы следует в отдельном штатном TextGrid View & Edit. Отмена
изменений Sound работает как в обычном SoundEditor; для точек траекторий
отдельной истории Undo в общем окне пока нет.

Если вычисляемый из Sound спектр не появляется, проверьте **Spectrogram →
Spectrogram settings → Window length (s)**. Для обычного речевого анализа
начните с **0.005** секунды. Гауссово окно требует звук длиной не менее двух
значений этого параметра: при 0.85 с нужен звук не короче 1.7 с. При ошибке
анализа редактор показывает сообщение в области спектрограммы. После изменения
настройки спектр пересчитывается сразу. Длина окна не влияет на кадры уже
загруженного SmartSpectrogram.
